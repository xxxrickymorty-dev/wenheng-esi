# 运行档案三指标 · 口径定义（票 06，2026-10-27）

> 目的：运行档案里能看到三个最小指标——**计划合法率、校验拦截率、单份时长**。
> 本文档是口径的唯一权威，避免以后各算各的。计算实现：`src/flexible/metrics.py`
> 的 `summarize(period_dir)`（纯函数、只读产物）；**不做 UI、不上大屏**
> （运行档案接线等票 04/05 过审后一起做）。

## 数据源（不新埋点）

- 每份灵活报告 = `out/<期次>/flexible/<intent>/` 一个目录，记一个样本；
- `flex_plan.json`：`backend`（`rule` 或 `openai:<model>`）、`fallback_reason`
  （模型规划被回退时为人话原因，否则 `null`）——票 01 产物；
- `flex_meta.json`：`check.pass`（终态自检）、`critic`（票 03 重规划轨迹：
  `rounds` / `escalated` / `hint` / `first_misses`）、`elapsed`
  （票 06 新增，generate 写盘时刻的耗时秒数）。
- 没跑完的半成品目录（无 `flex_meta.json`）**不算样本**。

## 指标一：计划合法率

- **分母**：模型参与规划的份数 —— `fallback_reason` 非空（模型规划被回退）
  或 `backend` 非 `rule`（模型规划直接成功）。
- **分子**：参与且未回退（模型规划直接被采纳）。
- 纯规则部署（零模型参与，如演示站）→ **`None`（不适用）**——
  不冒充 100%，避免"看着很好其实是没在测"。

## 指标二：校验拦截率（与交人率）

- **拦截**：首轮自检不过的份数 —— 有重规划轨迹（`critic.rounds ≥ 1`，
  含被救回的）**或** 终态不过（`check.pass == false`，含复用规划不重规划的稿）。
- **拦截率** = 拦截份数 / 总份数。
- **交人率** = `critic.escalated == true` 的份数 / 总份数
  （重规划一次后仍不过＝「需人工接手」，票 03）。
- 拦截不是坏事：红线设计就是"宁可拦下也不硬出稿"。

## 指标三：单份时长

- 每份取 `flex_meta.json` 的 `elapsed`（秒，generate 落盘时刻）。
- 汇总给 `n / mean / p50 / max`；**p50 取上中位**（偶数样本取右）。
- 无任何带时长的样本 → 各值 `None`。

## 边界约定

- 分母为 0 的率一律 `null`（不适用），前端/档案渲染时显示「不适用」；
- 率保留 3 位小数；时长保留 1 位小数；
- `summarize()` 只读不写，坏 JSON 产物按缺数据跳过（不炸汇总）。
