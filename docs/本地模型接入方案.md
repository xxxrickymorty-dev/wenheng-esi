# 本地小模型接入方案（文衡 · 不联网、不调外部 API）

## 1. 定位：模型只写文字，绝不碰数字

```
监测表 → 确定性流水线（解析/断言/计算/图表）→ 句骨架（数字已是槽位）
                                                        │
                                          ┌─────────────┴─────────────┐
                                          │  本地小模型（可选增强层）      │
                                          │  只做：润色/自然化语句         │
                                          │  防护盾：数字→[[n]]占位 →     │
                                          │  模型润色 → 校验 → 还原       │
                                          │  校验不过 → 自动回退原句      │
                                          └─────────────┬─────────────┘
                                                        ▼
                                        报告初稿（数字 100% 来自台账）
```

- 纯本地：Ollama 服务跑在 `127.0.0.1:11434`，模型文件在本机磁盘，**断网可跑**。
- 代码入口：`src/local_llm.py`（check / polish / draft 三个命令）。
- 流水线开关（后续接）：`run_pipeline.py --polish local` 时，报告文字改用润色版；不加开关 = 纯模板版。

## 2. 数字防护盾（防幻觉的硬机制）

1. `protect()`：段落里所有数字（含小数）替换为 `[[1]] [[2]]…`；
2. 模型只看到占位文本，提示词硬性要求"占位符原样保留、不得新增任何数字"；
3. `validate()`：① 每个占位符必须出现且仅出现一次 ② 剥离占位符后不得残留任何数字；
4. 任一失败 → `fallback` 回退模板原文。**模型出错的最坏结果是"文字不好看"，不可能改坏数字。**

## 3. 难点与对策

| 难点 | 说明 | 对策 |
|---|---|---|
| 数值幻觉 | 小模型更爱"顺手补数字" | 占位符防护盾 + 校验回退（已实现）；输出仍须过卜彤审批门 |
| 公文文风 | 小模型偏口语/AI 腔 | 提示词约束 + 低温度（0.2）；进阶：用馆内 38 期报告语料做 few-shot 样例，再不够才考虑 LoRA 轻调 |
| 硬件 | 本机为 AMD 核显（无 CUDA），只能 CPU 推理 | 先上 **qwen2.5:3b-instruct**（CPU 可跑，段级文本够用）；7b 慢约一倍；若要 14b 或更快，放阿里云 GPU 实例（同一套 Ollama 接口，换 URL 即可） |
| 速度 | CPU 生成一段 200~400 字约需数十秒 | 报告是"每两月一次、批处理"场景，整期 12 段约 10 分钟内，完全可接受；非交互式 |
| 版本漂移 | 换模型/换版本 → 文风变化、结果不可复现 | 固定模型 tag + 记录 digest（`ollama show --modelfile`），draft_texts.json 存档，签名留在红色件清单 |
| 合规 | 对外演示若含生成内容 | 模型许可需可商用（Qwen 系 Apache-2.0 ✓）；生成内容均标注"AI 起草、馆员确认"；公网 demo 前按需做生成式 AI 备案 |
| 运维 | 非技术馆员不会起服务 | Windows 开机自启 Ollama；`一键出报告.bat` 不管模型（纯模板照常出稿），润色是可选加成 |

## 4. 实施步骤（10 分钟）

```powershell
# 1) 启动 Ollama（装好桌面版则常驻；命令行方式）
ollama serve
# 2) 拉本地模型（一次，约 2GB）
ollama pull qwen2.5:3b-instruct
# 3) 验证
.venv\Scripts\python.exe src\local_llm.py check
# 4) 试润色一段
.venv\Scripts\python.exe src\local_llm.py polish "本期我校工程学较5月上升33.87%。"
# 5) 整期批量（对 out/<期次> 的句骨架）
.venv\Scripts\python.exe src\local_llm.py draft out\202607
```

## 5. 边界（不变的三条）

1. 数字、图表、断言、回测 = 确定性脚本，模型永不介入；
2. 报告发布仍走"红色件清单 + 馆员签单"审批门，模型产出的文字同样逐条列清单；
3. 台账与产出全部本地磁盘（input/out 目录），不上传任何云端。
