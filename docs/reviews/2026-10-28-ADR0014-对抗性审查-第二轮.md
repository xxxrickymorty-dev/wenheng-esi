## R2-1【S0】顶尖论文下降期，报告写「增加-11篇」

**指控**：句骨架把方向词写死为「增加」，只填绝对差 → 下降期出负号。

**证据（三处独立）**：

1. `src/sentences.py:493` 与 `:543` 各有一份：
   `f"…较上期总数增加{p1['top_papers_delta']}篇…"`
2. `out/202605/overview_facts.json`：`top_papers_delta = -11`
3. 成品 `out/202605/报告初稿_202605（试排）.docx` 解包实测，**命中 2 次**：

   > 本期我校共有252篇顶尖论文，较上期总数增加**-11**篇，覆盖【手工：学科】个学科。

**影响面（主代理实测）**：已有 5 期中 1 期中招。

| 期次 | delta | 会写成 |
|---|---|---|
| 202601 | 14 | 增加14篇 ✓ |
| 202603 | 18 | 增加18篇 ✓ |
| **202605** | **-11** | **增加-11篇 ✗** |
| 202607 | 22 | 增加22篇 ✓ |
| 202609 | 17 | 增加17篇 ✓ |

**同族未爆三处**（同一 bug 类，尚未命中）：
`sentences.py:489` 「分别上升{c1}%和{c2}%」（c2 可为负）；
`sentences.py:489-490` 「继续呈现较大降幅…下降{d}位」（全学科不降时 d=0，会写"较大降幅，下降0位"）；
`permille_years_est` 见 R2-4。

**修法**：抽一个 `_delta_phrase(delta)` —— `>0 → 增加 n`、`<0 → 减少 |n|`、`=0 → 持平`；
两处调用点同改；加参数化用例钉住 `delta ∈ {-11, 0, 14}`。

**不成立条件**：若 `top_papers_delta` 口径上恒非负——已由 202605 证伪。

## R2-2【S1】台账与已出版原件在多学科上差了 8 位，对照机制发现了却没归因

**指控**：相邻两期同格接不上；差异报告标了 ❌ 却只写「行级通过 21/22」，不解释。

**证据（主代理复核）**：

| 来源 | 多学科 · 国内排名/变化 |
|---|---|
| 原件 第 3 期 | `179/↑11` |
| 原件 第 4 期 | `167/↑12`（隐含上期 179） |
| 台账 `out/202605/table2.csv` | `171/↑19` |
| 台账 `out/202607/table2.csv` | `167/↑4`（隐含上期 171） |

`out/202607/对照差异报告_202607回测.md`：「❌ 多学科 · 国内排名/变化: 计算=167/↑4 手工=167/↑12」，
结论段只写「行级通过 21/22」，**无归因**。对比 202601 精神病学那条写明了「待馆员确认」。

**如果为真**：两份文件并排翻，第 4 期「上升 4 位」与第 3 期的 179 位自相矛盾。
更麻烦的是——它动摇了「台账是唯一事实源」这句立身之本：
**原件说 179，台账说 171，系统按台账算，于是与已盖章的第 3 期打架。**

**两种可能，必须定一种**：
- 台账 202605 多学科格填错（171 应为 179）→ 改台账，重跑 202605/202607；
- 原件第 3 期印刷错 → 差异报告写明并进红件清单，加「跨期 rank 对齐」断言。

**修法**：`compute.fmt_rank_change` 增加一条跨期校验——本期 rank 与上一期报告大表 rank 必须能对上，
对不上就进 `warns`，不允许只挂在「21/22」里。

## R2-3【S1】「STEPS 是唯一事实源」在代码里不成立：5 步 vs 实际 7 步

**指控**：省域表与矩阵两步不在 `STEPS`，缺数据时静默 `return 0`，红件清单无记录，状态仍 `completed`。

**证据（主代理复核）**：

- `src/agent/flow.py:35-46`：`parse / compute / forecast / charts / docx`（5 步）
- `src/run_pipeline.py:218 / 236`：`_emit("province"…)`、`_emit("matrix"…)` —— 真实步骤，不在 STEPS
- `src/fill_docx.py:117-118 / 171-172 / 178-180`：`if not p.exists(): return 0`、`if t19 is None: return 0`
  —— **既不 `slots.append`，也不 `warns.append`**

**如果为真**：T19（13×10）与 T20（22×11）整表空着，报告状态 `completed`，
红件清单显示「无预警」，签单人签的是一份看起来完整、实则两张表全空的稿。

**修法**：两选一，必须选——
（a）把 `province` / `matrix` 补进 `STEPS`；
（b）在 `STEPS` 注释里写明「它不是完整产线的唯一事实源」，
并让 `fill_*` 缺文件时 `warns.append` ＋ `slots.append`。
**现状是措辞与执行不一致**，这比 bug 本身更危险（红线被当成已经守住）。

## R2-4【S1】第一个学科进 1‰ 的那一期，同段自相矛盾

**指控**：`permille_years_est` 算出负零 → falsy → 走「尚难估算」分支，与前半句「已有学科进入前1‰」打架。

**证据（主代理复算）**：

```
prox=105, prev=100 → growth=(105-100)*6=30
years = -(-(100-105)//30) = -0.0
bool(-0.0) == False  →  sentences.py:473 走 else 分支
```

前半句 `sentences.py:471`：`"，其中已有学科进入前1‰" if any_1permille`。

**如果为真**：全项目在等「第一个进 1‰ 的学科」，等来的那一期写
「已有学科进入前 1‰……尚难估算何时进入前 1‰」。这是里程碑当期最显眼的一句。

**修法**：`prox >= 100` 直接出「已进入前1‰」句式；`if years:` 改 `if years is not None`；顺手修负零。
