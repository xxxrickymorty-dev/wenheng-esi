## 一、一句话流程

**登录 → 把台账放进去 → 一键生成（约 20 秒）→ 看产出 → 下载初稿 → 在 Word 里补【手工：】→ 回网站复核 → 钤印签单**

首屏不是控制台，是**最新一期的对勘本**——报告才是主角，跑流水线是手段。

## 三、逐步操作

### 第 0 步 · 登录
打开网址 → 自动跳登录页 → 输入账号密码。
登录后落在**对勘本**（最新一期）。没有可对勘的期次时，会退回控制台。

### 第 1 步 · 把台账放进去（两种方式，选一种）
进控制台（`/run`）：

- **方式 A：选已有台账** —— 「选择已有台账」下拉里选期次（下拉项标着更新时间）→ 直接生成。
  台账已经在服务器上时用这个。
- **方式 B：上传新台账** —— 「台账文件（.xlsx）」选文件 + 「期次（上传时必填）」填 6 位数（如 `202609`）→ 生成。
  台账更新要求：**只动当期列、历史列一字不动**。在取数台完成的并入由系统自动保证这一点（写前备份、写后逐格核对）；
  按老办法手工贴表时：新一期列贴在对应工作表已有列后面，《千分之一被引阈值》表**按列追加、不要覆盖**历史列。

> 「附加金样回测」勾选框：只有需要与**已出版手工版**逐格比对时才勾（服务器上配了参考原件才出现）。

### 第 2 步 · 一键生成
点 **「一 键 生 成」**。约 20 秒，页面跳到任务页，看 **「01 流水线进度」** 五道工序依次走完：

| 工序 | 在做什么 |
|---|---|
| 解析台账 | 22 个工作表归一化 + 机器断言 |
| 计算大表与概述 | 22 学科 × 11 列 + 概述数字事实 |
| 预测回测 | InCites + 历史差值校准（MAPE < 5%） |
| 图表渲染 | 16 学科 × 6 图 + 概览图 |
| 母版替换 | 红色件原地替换 → 报告初稿 + 红件清单 |

### 第 3 步 · 看结果（任务页五块）
| 块 | 看什么 | 判据 |
|---|---|---|
| 01 流水线进度 | 五步是否走完，每步还带一句产出摘要（如「当期 202607 · 上期 202605 · 机器断言 全绿」「整体 MAPE 1.26%」「99 张图」） | **全绿 = 成功** |
| 02 运行信息 | 任务号 / 期次 / 输入文件 / 发起人 / 耗时 + 「运行档案·图表图册·对勘本」直达链接 | |
| 03 任务瀑布 | 每步耗时（实测：解析 0.7s · 计算 0.1s · 预测回测 1.0s · 图表 18.2s · 母版 3.1s） | 参考用 |
| 04 控制台输出 | 有红字就是有问题 | 断言会写明**缺哪张表哪一列** |
| 05 产出 | 八项产物 + 下载 | 见下表 |

**「05 产出」的八项**（实测）：

| 产物 | 说明 |
|---|---|
| 报告初稿（Word） | 主体交付：`报告初稿_<期次>（试排）.docx` |
| 对勘本（正文级对照） | 在线查看，即首屏那一页 |
| 红色件清单（Markdown） | 签单依据，可下载 |
| 红色件清单（逐格在线查看） | 网页版，可搜索 |
| 预测回测报告 | MAPE 精度 |
| 大表数据（CSV） | `table2.csv`，Excel 可开 |
| 红色件审计明细（JSON） | `red_slots.json`，逐格来源 |
| 运行日志（JSON） | `run_log.json`，排错用 |

> **运行信息里的「期次 202609（台账检测 202607）」怎么读**：前面是你上传时填的期次，
> 括号里是**台账里实际检测到的当期列**。两者不一致 = 台账里新一期的数据列还没贴全，
> 产物名会跟着检测到的期次走。**贴全了才会一致。**

**失败长什么样**：进度停住 + 控制台红字「断言 FAIL：宽表 XX 含期次 202609」→ 台账缺这一列 → 补上 → 点 **「重 跑 本 期」**。
（重跑会把上一版稿子隔离到 `_superseded/`，不会悄悄覆盖。）

### 第 4 步 · 复核（签单前必做）
1. **下载报告初稿**（任务页「05 产出」→ 报告初稿（Word））→ Word 打开 → 搜索 **【手工：】** → 共 6 类待填：
   ESI 发布日期、当期全球机构总数、去年同期升幅%、学院贡献度、省级高校总数、目录页码。
   ⚠️ **这版网站没有在线填**，就在 Word 里按老习惯填。
2. **对勘本**（首屏）：左栏槽位分组（封面 / 概述正文 / 发展趋势 / 学科态势 / 大表与表题 / 学科图表槽位 / 顶尖论文 / 预测回测 / 云南省对比 / 概览图槽位）；
   中栏改动卡；右栏「校记」显示每处的台账出处。页头写明**本期改动 354 处**、待人工补录 7 处、机器断言 50/50 全绿。
   右侧有 **「朱批层」「仅看待人工」** 开关；按 **← →** 换分组。
3. **红色件清单**：共 **354 条**，按类分组（大表数值格 239 / 正文 15 / 封面 2 / 各学科图槽各 6 …），
   每条列出「改了什么、来自哪里」——**这是签单的依据**；带搜索框（匹配 x/354），可下载 Markdown。
4. **图册**：共 **99 张**，按学科平铺，点开看原图。

### 第 5 步 · 签单
在对勘本右上的签单区（写着「**待签人 馆员 · 学科服务部**」）：写批注（可选）→ 若还有【手工：】项，勾「已知悉并放行」→ 点 **「钤印签单」**。

**两道闸（服务端拦的，不是界面藏按钮）**：
- 闸一：机器断言有 FAIL → 不放行，先补数据重跑；
- 闸二：还有【手工：】项没处理 → 必须**显式勾选知悉**（勾没勾会写进审批记录）。

对勘本右栏还会实时显示三道闸的状态：**机器断言闸 全绿 / 金样回测闸 逐格比对 / 人工审批门 待签单**。

签完：期次状态变**已签发**（印记链上那枚印变样），服务器留 `审批记录.md`（谁、什么时候、批注、当时的产物指纹）。

**两个要知道的**：
- **改了就失效**：重跑一次报告，产物指纹变了，签名自动失效并提示重签；
- **签错能撤**：点「撤回」，历史保留（不是删记录）。

## 四、五道工序 / 三道关

- **五道工序**：见上表（控制台与任务页显示的是同一份，来自流水线唯一事实源）。
- **三道关**（控制台页脚原文）：
  1. **机器断言**：当期列完整性、22 学科名单、跨章节数字互检，缺项即拦停；

  3. **人工审批**：对勘本逐条列明「改了什么、来自哪个单元格」，馆员钤印签单后报送。

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 生成后任务不动 | 看任务页「04 控制台输出」；仍不动把运行日志（JSON）发给开发 |
| 断言 FAIL：宽表 XX 含期次 2026XX | 台账里那张表还没贴当期数据，补上再重跑 |
| 断言 FAIL：千分之一阈值含 2026XX | 《千分之一被引阈值》表没贴当期列 |
| 任务页写「期次 202609（台账检测 202607）」 | 台账里新一期的列还没贴全，产物名会跟着检测到的期次走 |
| 签单被拒 | 看提示：断言 FAIL → 补数据重跑；待人工 → 勾「已知悉并放行」 |
| 忘了控制台地址 | 首页地址后加 `/run`，或点对勘本面包屑「发起任务 / 历史任务」 |
| 图表里中文是方框 | 服务器缺中文字体，找开发（`fonts-noto-cjk`） |
| 控制台输出里有 `mkdir -p failed for path /var/www/.config/matplotlib` | 服务器上服务用户的家目录写不了 matplotlib 缓存（**不影响出稿**，只是每次都刷这条警告）。要清掉：给服务设 `MPLCONFIGDIR` 或 HOME 后重启服务 |
| 登录一直失败 | 密码改过要重启服务，找开发 |
| 想重跑 | 任务页「重 跑 本 期」；可重复运行，旧稿会隔离不丢 |

## 七、给馆员的一页速记（可打印）

**每期三步**：
1. **取数并入**：取数台一路做完「下载 → 逐份核验 → 核对本期监测表 → 并入台账」（下载跑在装了取数浏览器的机器上；
   网站上的取数台随时可看核验结果与核对明细）
2. **生成**：登录网站 → 控制台 → 选/上传台账（填 6 位期次）→ 一键生成 → 等约 20 秒 → 看五步全绿
3. **补手工**：下载报告初稿 → Word 里搜【手工：】补 6 类 → 对照红色件清单复核 → 回网站签单

**找开发的情形**（不用每次找）：
- 台账**新增工作表/列**或改了表头写法 → 解析器要先适配（把新台账发来）
- 图表要换样式、想改口径、报告里有看不懂的异常
- 服务器报错 / 页面打不开
