# 消融实验设计：对话问答（基线＝裸 DeepSeek）

- **状态**：设计稿（2026-10-12，rick 定「先出设计稿，新会话执行」）
- **执行者**：新会话——读本文件即可开工；仓库纪律见 `wenheng/AGENTS.md`
- **目的**：把文衡对话问答「约束层」的贡献**量化**——数字正确、可溯源、不编造、离线可用，各值多少
- **用途**：申报/答辩材料（含代价面，如实披露）

## 0. 一句话

同一套问题、同一个模型（DeepSeek，同参数），**只变「约束」**：从「无约束直连 API」（A0）
到「完整文衡管线」（A4），逐档加组件，量化每档的数字正确率 / 可溯源率 / 不编率与代价。

## 1. 组别（消融梯度：每档只加一个组件）

| 组 | 加什么 | 实现路径（在 `wenheng/` 下） |
|---|---|---|
| **A0 裸 API（基线）** | 什么都不加：用户问题直发 API，无 system | 直连 `WENHENG_AI_BASE_URL`（OpenAI 兼容 `/chat/completions`）；参数与系统一致：`temperature 0.2 / max_tokens 8192 / timeout 30s`（max_tokens 取部署 env 实际值 8192，`_brain` 缺省 2048 已被 env 覆盖；2026-10-13 rick 定稿） |
| A1 裸 API＋公平提示 | 一句中性 system | 同 A0，system＝「你是云南大学图书馆的数据助手，请尽量准确回答。」 |
| A2 ＋报告文本 | 把该期报告事实段塞进 prompt | context 取 `out/<期次>/overview_facts.json` 文本（按问句关键词粗筛，取不到给前 ~3000 字）；直连 API 出答案 |
| A3 ＋台账证据（无盾） | 引擎取出的台账段直给模型，答案**不做任何校验** | 复用 `src/ai/_plan.py`（`rule_specs`）＋ `flexible/queries.py`（`execute`）＋ `src/ai/_evidence.py`（`assemble`）拼证据文本；直连 API 出答案 |
| A4 完整管线 | 规划器＋引擎＋证据＋盾＋校验＋回落 | `ai.run("qa", period, payload={"question":…, "history":…}, actor="admin")`（配 `ai.using(data_root=Path("out"))`） |
| A5 完整管线·断模型 | 强制规则版（无 key / 断网场景） | 临时 env `WENHENG_AI_PROFILE=demo`（`src/ai/_config.py` 的规则锁）后走 A4 |

**关键对照**：A0↔A3 ＝有没有数据；A3↔A4 ＝盾与校验的贡献；A4↔A5 ＝模型不可用时的兜底。

## 2. 题库（6 类 × 4 题 ≈ 24 题 + 3 段多轮）

| 类 | 考什么 | 题例 | 来源标注 |
|---|---|---|---|
| 1 台账数字直查 | 数字准不准 | 化学的接近度最新一期是多少 | 实问 |
| 2 多期趋势 | 多期取数 | 化学的接近度最近几期怎么变的 | 实问 |
| 3 报告里没有·台账里有 | 报告外取数 | 202603 的化学接近度是多少 | 构造 |
| 4 多轮指代 | 上下文解析 | 「它最近怎么样」（上文指学科） | 实问 |
| 5 台账里也没有 | **不编** | 医学院的排名是多少（不在 22 学科） | 构造 |
| 6 期次口径 | 期次解析 | 9 月这一期化学的接近度 | 构造 |

- 题库文件：`tools/ablation_questions.json`。每题字段：
  `id / q / period / category / source(实问|构造) / expect(作答|如实说无) / gold`。
- **金标取数**（逐题带台账格指针）：
  ```python
  from flexible.datasource import DataSource
  from flexible import queries
  ds = DataSource(Path("out/202609"))          # 期次用 202609（台账最新、产物齐）
  r = queries.series(ds, "proximity_1pct", "Chemistry")   # → points[{period,value,source}]
  ```
  注意口径：接近度等比值在报告里显示为 ×100 两位小数（如 `676.06%`）——评分时两边都归一化。
- 真实问法沉淀参考：`src/ai/plan_examples.json`、`tools/qa_gold.json`、`.workbuddy/memory/`。
- 多轮 3 段：如「化学的接近度是多少」→「它最近怎么样」；`history` 原样传给各组。

## 3. 指标与评分

- **数字正确率** ＝ 回答里出现的台账数字命中金标格的比例（自动：正则 `\d+(?:\.\d+)?` 抽取 → 与 gold 归一化比对）
- **编造率** ＝ 与台账冲突/不存在的数字占比；**致命编造**单列（接近但错：18181→18118 类）
- **可溯源率** ＝ 数字能指回台账格的比例（A4 用 `Answer.sources` 自动算；A0–A3 结构上为 0）
- **不编率**（第 5 类）＝ 如实说「查不到 / 无此数据 / 不在名单」的比例
- **期次正确**（第 6 类）＝ 答的是不是问的那一期
- **稳定性** ＝ 每题每组重复 3 次（同参数）——裸模型编造的数字逐次不同，**方差本身是证据**
- **代价面**（如实披露）＝ 延迟、token 成本、断网可用性

评分流程：自动为主 → `report.md` 出对比表 → 争议条目人工复核（双人抽检 20%）。

## 4. 执行细则

- **脚本**：`tools/ablation_qa.py`（新写、单文件可跑）：
  `uv run python tools\ablation_qa.py --groups A0,A1,A2,A3,A4,A5 --repeat 3`；先 `--limit 8` 小样本给 rick 过目
- **参数**：所有组同一模型同一参数（读 `server/.env` 的 `WENHENG_AI_*`）；**key 只读 env，不落盘、不打印**
- **产物**：`out/_ablation/<时间戳>/`（新建目录，不碰既有数据）：
  - `results.jsonl`——每次调用一条：`{group, qid, run, answer, elapsed_ms, model, ts}`
  - `report.md`——指标 × 组别对比表 + 关键样例原文
  - 需要时 `raw/` 留原始响应
- **红线**：既有数据一律只读。A4/A5 走 `ai.run` 会在 `out/<期次>/ai_calls.jsonl` **追加**运行留痕
  （系统正常行为）；若要零写入，把 `out/<期次>/` 必要文件与 `input/<期次>/监测表.xlsx` 拷到
  `tmp/ablation-root/` 再跑（`ai.using(data_root=…)`）。
- **成本预估**：~350–400 次调用（24 题 × 4 直连组 × 3 次 + A4/A5）≈ 几元级；串行 1–2 小时。
- **记录**：模型名与日期写进 `report.md`（模型漂移留痕）。

## 5. 公平性与效度（防答辩被挑）

① 裸模型给足机会：A1 档 ＋ 重复取平均；② 题库「实问＋中性构造」各半，不专门为难；
③ 评分盲化：组别编号打乱、双人抽检；④ 只变约束、不换模型；⑤ 指标预注册（本文件即预注册）。
