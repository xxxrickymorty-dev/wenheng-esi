| 四问 | 结论 |

## 二、启发式违规清单（Nielsen 10 · 带证据与优先级）

**H1 系统状态可见性**
- **P1** 审核台自相矛盾：「报告里的空 **6 处（待填 0）**」与「有 **6 处填写还没写进报告**」并置——签单前最该清楚的一步反而含糊。
- **P2** 对话首页「本期动态 · 202611 ①取数● ②…○ ③…○」用 ●/○ 表示状态却**无图例**。

**H2 系统与真实世界的匹配**
- **P2** AI 分析台把「规划后端：`openai:deepseek-flash` / `openai:deepseek-v4.1-flash`」直接暴露给用户（UX.md 禁技术术语；`web/AGENTS.md` 交付纪律②）。
- **P2** 「盾 · 2 个数字已登记」——「盾」为内部黑话。
- **P3** 「期次印记链」用「朱印/金印/墨线框」「点**一笺**换一期」文学化；有图例但"笺"生僻。

**H3 用户控制与自由**
- ✅ 追问有「先等等」；危险按钮有 title 提示。
- **P1** **「重新生成」无行内二次确认**：`web/src/Flexible.tsx:309` 直接触发覆盖逻辑，未走仓库自带的 `ConfirmButton`——与 UX.md §十「破坏性动作先确认、行内二次确认」冲突。

**H4 一致性与标准**
- **P3** 陈列馆「进入 3D 图书馆」×3；对话页「去生成台」×2——重复 CTA。

**H5 错误预防**
- ✅ 数字盾 + 来源链；签单前勾选「我已逐项看过…」。
- ⚠️ 审核台文案矛盾（见 H1）构成误操作风险。

**H6 识别优于回忆**
- ✅ 示例芯片、可用期次下拉、名词解释。
- **P2** 对话首页三枚胶囊「出报告/查数据/看进展」视觉像**筛选标签**，实为"把示例句填进输入框"；只有 a11y `description` 说明，肉眼无从区分。

**H7 灵活高效**
- ✅ 示例句一键填、期次自动识别、「查最新的」一键。
- ⚠️ 分析台两栏各 6 张图、判断节重复整段数字序列，阅读负担重。

**H8 美观与极简 / 视觉基线**
- **P2 对比度**：实测陈列馆「**试试：**」（功能性提示）仅 **2.93:1**，「01」2.14、「ASK WENHENG」4.22——低于 UX.md 自定 AA 4.5:1（其余多为 8–9px 装饰英文眉标）。
- **P2 字号**：陈列馆 **76 个**文本节点 <13.5px；工作区/审核台 **23 处**（`.ws-cap` 12px、`.rv-chip` 12.5px、`.rv-todo-v` 12px…）——与「最小标签 13.5px」冲突。
- **P2 点击区**：审核台 **20 个** <32px（最小「← 回报告」24px、主题切换 13×13、「看对勘本」18px）；陈列馆页脚链接 22px——低于「≥44px」。
- **P2 滚动揭示动效**：`.home-reveal` 默认 `opacity:0`、靠 JS 揭示——**整页截图 / 打印 / og:image 会大片空白**（实测 fullPage 截图下半屏全空，须真滚动才显现）。

**H9 帮助用户识别、诊断、恢复**
- ⚠️ 回退说明停在机制层（见 T1）；空/错态本身说得不错。

**H10 帮助与文档**
- ✅ 全站唯一「说明·口径、来源与只读声明」＋名词解释；⚠️ 该段约 90+ 字偏长。

| 页面 | <13.5px 文本 | 低对比度命中 | 点击区 <32px | 缺 alt | 可见技术串 |

| 工作区 / 审核台 | **23** | — | **20** | 0 ✅ | 2（模型串） |

复现（浏览器控制台）：
```js
// 统计 <13.5px 文本、低对比度、点击区、缺 alt
[...document.querySelectorAll('body *')].filter(e=>e.childElementCount===0&&e.textContent.trim()&&parseFloat(getComputedStyle(e).fontSize)<13.5).length
```

## 四、优先级与分工建议

**总原则**：`web/src/index.css` 是**唯一碰撞点**，按**命名空间分段**并行——各流只改自己那段（`.home-*` / `.dlg-*` / `.fx-*` / `.rv-*` / `.ws-*`）；跨段或全局令牌改动**只由 W0 做**。

| 流 | 归属面 | 文件边界 | 含项 | 依赖 |
|---|---|---|---|---|
| **W0 基础层** | 全局令牌/度量 | `web/src/index.css`（全局段）、`web/src/lib/banned.ts` | P2 对比度补 AA、字号拉回 ≥13.5px、点击区 ≥44/32px；把 `盾 / 规划后端 / openai: / deepseek` 加进禁用词单源 | 先做、独占 |
| **W1 陈列馆** | 评委首屏 | `web/src/shelf/**`、`index.css` 的 `.home-*` 段 | **P0 首屏补产品名「文衡」+ 一条规模事实**；P3 去重复 CTA；P2 揭示动效的 no-JS/截图兜底（默认可见，JS 再加动效） | W0 后 |
| **W2 工作区壳/审核台** | 馆员主链 | `web/src/Review*.tsx`、`web/src/App.tsx`（侧栏/页题）、`.rv-*`/`.ws-*` 段 | **P1 审核台「6 处」矛盾文案**；P2 点击区（回报告/看对勘本/主题切换） | W0 后 |
| **W3 对话前门** | 唯一输入口 | `web/src/dialog/**`、`.dlg-*` 段 | P2 「盾/数字校验」改人话、回退说明给"下一步"；三胶囊视觉区分；「本期动态」●/○ 加图例；追问卡加「已选」态 | W0 后 |
| **W4 AI 分析台** | 第二产线 | `web/src/Flexible.tsx`、`.fx-*` 段 | **P1「重新生成」接 `ConfirmButton`**；P2 撤下「规划后端:模型串」；判断节数字密度减负 | W0 后 |

**串并行**：W0 单独先跑一轮（约 1 单元）→ W1–W4 四流并行（文件边界互不重叠）。

**每流验收门（缺一不可）**：
1. `cd web; npm run build` 且**提交 `dist/`**（`web/AGENTS.md` 硬规则①）；
2. `uv run python -m pytest tests/test_stack_contract.py`（契约）；
3. `& "$env:LOCALAPPDATA\Programs\Python\Python313\python.exe" ../tools/check_web_app.py`（真浏览器端到端，零报错）；
4. 本报告 §三 的 DOM 审计脚本：相关指标**归零**（如 W0 后功能文本 0 命中 <13.5px、0 命中 <4.5:1）。

**建议**：P0/P1 三条（陈列馆首屏、审核台文案、重新生成确认）进"材料定稿前必做"；P2 字号/对比度/点击区集中在 W0 一次清掉，避免各流各改指数爆炸。
