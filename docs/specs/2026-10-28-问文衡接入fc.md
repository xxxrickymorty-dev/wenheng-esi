  本篇 §契约2 的「结果追加进 `Brief.evidence`」由工具消息取代。
- （原设计定稿：rick 口谕「先把问文衡接入 fc」；依 10-26 fc 审查「问答只读取证可接」+《LLM 侧架构》草案不变量）
- **关系**：《2026-10-12-LLM侧架构》的**续篇**——规划轮（规则→模型，文本 JSON）不动；本次给**写作轮**加原生工具环：模型可自主拉取证据，宿主按白名单只读取数。

## 契约（三层）

1. **适配器**（`_brain.OpenAIBrain.think`）：`Brief.tools` 非空 → payload 带 `"tools"`（OpenAI function schema，仅名字/描述，零数字）；响应 `message.tool_calls` → `Turn(calls=({"name", "arguments"(已解码 dict)}, …))`。单发语义不变（循环在边界）；RuleBrain 原样（永不发 tools）。
2. **边界**（`_attempt.attempt`）新形参：`execute=None`（宿主执行器回调）、`max_steps=1`。循环：think → `turn.calls` 非空且 `execute` 可用 → 逐调用执行 → 结果文本**必须已是占位面**（执行器侧注册过编号）→ 追加进 `Brief.evidence`（step+1）→ 再 think；末轮仍 calls → 按 `CALLS_UNSUPPORTED` 回落（notice 说「模型连续请求工具未作答」）。边界职责：egress **累计**预算（超限→egress_budget 回落）、执行器异常→回落、对执行器返回文本做**零裸数字守卫**（`strip_marks` 后 `visible_digits` 非空＝执行器违约→GUARD_REJECT 回落）、收集回执。`Outcome` 增 `receipts: tuple[Receipt, …]`。已有路径（无 tools）逐字不变。
3. **qa 执行器**（`_qa.build` 闭包，`RuleDraft` 增 `tools` / `execute` / `max_steps=2`）：
   - 工具面＝引擎只读白名单（与 `_plan` 同表）：`query_series / query_events / query_overall_rank / query_at`（+`compare/delta` 如引擎已支持），schema 描述用馆员话术、**零数字**；指标走 `_plan.MODEL_METRICS` 无数字别名，学科按 `view.disciplines` 白名单。
   - 执行：校验参数（越权→**拒**：返回一句无数字人话「该查询不在可查范围」+`Receipt(ok=False, refused=True)`，不回落——模型可继续作答）→ 与 `_ledger_evidence` 同款切窗/补期次 → `queries.execute` → `_evidence.assemble` 单结果 → **`NumberedText.append` 续号注册**（cells 精确格指针，fact=True）→ 返回占位面文本。同规格去重（memo：命中直接复用已注册文本）。
   - 回执：`Receipt(tool=f"query_{op}", label="查台账", args_digest=_record.digest(args), summary="查 化学·接近度（近六期）", ok, elapsed_ms)`——summary 只含名字零数字。
4. **编号续接**（`_numbered.NumberedText.append`）：类方法 `append(nt, texts, register) -> NumberedText`——`k` 从既有最大续号，**原地**合并进 `nt.mapping`（dict 同一对象，`draft.mapping` 引用者自动看到）；sources/fact_keys 续接。`_core.run` 传给 attempt 的 mapping 引用始终有效。

## 留痕与界面

- 一次 qa 调用仍**一条** ai_calls（`plan` 字段既有）；回执进 `tools` 字段（digest 面）与 `Answer.receipts`（界面面）——`_publish(receipts=draft.receipts + outcome.receipts)`，管道 receipts-lite 已铺好。
- 界面：复用 `web/src/dialog/DialogPage.tsx` 的 `ReceiptBar`（既有件，零新设计）挂到 AnswerBlock 与 qa 呈现面；文案「查台账」。

## 开关与回落

- 跟随 qa 能力开关（无新旋钮）；演示站规则锁 / 无 key → RuleBrain，物理上无工具环；云适配器失败→回落规则版（现状语义）；模型不用工具→与现状逐字一致。

## 测试（先红后绿；缝＝attempt + build）

- 边界：ScriptedBrain 发 calls→执行器被调→第二轮作答→receipts 在 Outcome；执行器抛异常→回落规则版；执行器返回裸数字→GUARD_REJECT；末轮仍 calls→CALLS_UNSUPPORTED；egress 累计超限；无 tools 路径逐字不变（既有用例全过）。
- 适配器：payload 带 tools 的请求形状（Scripted/录 Golden）；tool_calls 解码；坏 arguments JSON→BrainError(bad_response)。
- qa：越权指标/学科→refused 回执+无数字拒答句；合法查询→数字注册进同一 mapping（used_by 指到台账格）；同规格去重；Answer.receipts 非空；越题判定不受影响（工具结果是 fact）；既有 qa 用例全过（行为保持）。
- 红队：执行器输出裸数字必被边界拦（防线不依赖执行器自觉）。

## 范围外

- 灵活线/固定线/写作位不接（各按 ADR-0005 阶梯另案）；对话内核（pi 自有环）不动；规划轮不改原生 fc（文本 JSON 已够、改动小）；向量检索；写操作工具（永不）。
