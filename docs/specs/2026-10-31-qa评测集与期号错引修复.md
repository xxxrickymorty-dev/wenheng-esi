# spec：qa 评测集固化＋期号错引修复＋被拒候选落留痕

- **状态**：设计定稿（2026-10-31 深夜，rick 口谕「继续」）。三票待落码。
- **关系**：盾拒恢复（票 04，已合 main）之后的收尾三票。A/B 实验残留观察项＝
  期号错引进数值槽（两臂各 1 例，盾放行——语义错非数值错）。

## 病例与根因

- **期号错引**：答案把「期次编号」的标记写进数值槽（如「接近度 **202609%**」）。
  根因在证据面：`_evidence._at` 渲染为「…单期值（台账《X》表）：202609 [[58]]。」——
  **期次与值的标记相邻且期次在前**，模型扫读时分不清谁是值。提示语句
  （7505bce0 已加）不够，A/B 两臂仍各漏 1 例。
- **盾拒不可复盘**：留痕 `fallback_detail` 只记 stray 的**数量**（`_core` 把 detail
  值都转成 len），被拒稿原文不落盘，复盘靠抓包（dsh 口径 "model-visible means
  logged"：失败尝试也该可重建）。

## 契约（三票）

### 票 A 评测集固化（`tools/qa_eval.py` + `config/qa_eval_cases.json`）

- **金问集**（20–30 例，JSON 数组；期望值**运行时从引擎读**，严禁硬编码数值——
  数据更新不破）：字段 `{id, group, question, history?, period, expect}`；
  `expect`：
  - `values`: `[{metric, disc, period?}]`——runner 用 `flexible.queries.execute`
    解出期望值，断言还原后答案文本**包含**该值串（int 按不带千分位的十进制串）；
  - `ops`: `["query_at", …]`——断言 `Answer.receipts` 的工具名**包含**这些
    （澄清类可不填）；
  - `mode`: `"model"`（缺省）；澄清类允许 `fallback in (None, "off_topic")`。
- **覆盖矩阵**（每组至少 2 例）：直问单指标（1%/1‰/接近度/论文数/CNCI）、
  追问省略主语（「查最新的」）、追问期次（「那上一期呢」）、比较题（CNCI 谁高）、
  多学科多指标、报告别名（热点论文→顶尖论文）、越权学科（名单外→refused 回执
  ＋如实说明）、笼统问句（→澄清）、走势（→query_series）、整体排名、
  点名历史期次（focus_period）。
- **runner**（`tools/qa_eval.py`）：`--model <models.json 的 id>`（缺省当前部署）、
  `--case <id>`（单跑）、`--repeat N`（默认 1）；逐例 `ai.run("qa", …)`（默认数据根）；
  输出逐例 PASS/FAIL＋原因、组统计（通过/盾拒/回落码分布/耗时），非 0 退出码＝有 FAIL。
  **手动工具，不进 pytest 收集**（真网关花钱；文件头 docstring 写明用法与判据）。
- 留痕照写 `ai_calls.jsonl`（诚实审计，运行前在输出里提示一句）。

### 票 B 期号错引修复（`src/ai/_evidence.py` `_at`）

- `_at` 渲染改为：期次进括注、值的标记紧贴冒号后——
  `f"{cn} · {cn_metric} · 单期值（{p} 期，台账《{sheet}》表）：{v}。"`。
  `_series`（期次-值天然成对）与 `_compare/_events/_overall` **不动**。
- `cells` 注册口径不变（值↔格指针照旧）；grep 旧格式的测试断言同步改写，
  语义断言（含值、含期次、来源指到格）一个不许丢。

### 票 C 被拒候选落留痕（`src/ai/_attempt.py` + `_core.py`）

- `_attempt`：`SHIELD_REJECT`（含恢复后再拒）的 `detail` 增 `"masked_head"`＝
  `_mask_digits(candidate)[:200]`（占位面，零数字构造保证）；`stray` 照旧。
- `_core.run`：`fallback_detail` 不再一律 `{k: len(v)}`——`shield_reject` 的
  detail **原样透传**（masked_head 与 stray 都是可留痕面）；其余回落码维持 len 口径。
- 界面/`Answer` 不动（记录面 only）。
