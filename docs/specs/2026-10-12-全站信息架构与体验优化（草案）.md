- **状态**：待 rick 审（先方案、后静态稿、再改代码）

## 0. 一句话

把全站收敛成三个清晰的面：**看（陈列馆）· 问（文衡）· 做（工作台）**。
登录先进「看」，从「看」一步到「问」，馆员从「问」进「做」。
视觉沿用现有学术编辑风（云大绿 / 纸色 / 衬线），只做**统一与卫生**，不推倒重来。

## 1. 用户要素盘点

| 用户 | 账号 | 目标（一句话） | 入口 | 权限 | 情绪诉求 |
|---|---|---|---|---|---|
| 评委 / 观众 | `demo`（操作员） | 看懂「这东西解决了什么」，翻报告、问数据 | 登录 → 陈列馆 | 只读 | 不迷路、不被术语吓到、有惊艳感 |
| 馆员 / 演示者 | `admin`（管理员） | 演示全链路：出稿 / 签单 / 答疑 | 登录 → 陈列馆 → 文衡 → 工作台 | 全部 | 快、可控、专业 |
| 未登录 | — | 登录 | `/login` | 无 | 明白这是啥 |

## 2. 现状诊断（用户视角的四个「乱」）

1. **入口乱**：登录落工作台；陈列馆的「回工作区」又回工作台；对话页 / 工作台 / 陈列馆
   三处互相跳，没有「主屏」。
2. **叙事乱**：陈列馆＝看、工作台＝做、对话＝问——三面各自成立，但没人告诉用户「先看哪、再去哪」。
3. **对话页首屏弱**：空态只有一张「本期任务」卡，不像一个能开口就问的助手（对照 WorkBuddy 主页）。
4. **细节卫生**（design-audit 实测 `web/src` 73 文件）：
   - CRITICAL：3 处去掉了焦点框没补（`dialog/dialog.css:180`、`index.css:360`、`library/library.css:454`）；
   - CRITICAL：2 处可点 `div` 无键盘支持（`AiRecords.tsx:133`、`Flexible.tsx:302`）；
   - IMPORTANT：34 处 hover 无过渡（6 个 css 文件）；
   - 动效时长 / 缓动未成体系；`prefers-reduced-motion` 已在关键处处理（6 css + 2 tsx），不用大手术。

## 3. 目标信息架构（IA）

```
登录 → 陈列馆（看）─┬─ 进入 3D 图书馆 → 翻书阅读（报告全内容）
                    ├─ 「问文衡」入口 → 文衡对话页（问）
                    └─ 「去问文衡」（原回工作区）→ 文衡对话页 →「工作台▾」→ 生成台/报告/审核/预测…
```

- **看 · 问 · 做** 三面；「问」是枢纽：从看一步达、从问可达做。
- 工作区导航保留现有 7 项；「对话前门」文案改「文衡」（品牌一致），陈列馆入口保留。

## 4. 页面级改造清单

### P0（评委路径闭环，先做）

1. **登录落点** → `/app/shelf/`（两角色一致）。
2. **陈列馆首页加「问文衡」入口**：hero 的「学科检索」旁一枚按钮，或馆藏区上方一条带
   （输入框 + 3 个示例胶囊）；提交 → `/app/dialog/?ask=…`，对话页读参数**自动发送**。
3. **文衡对话页空态重排**（WorkBuddy 风）：
   - 大标题（候选：A「文衡，我帮你」/ B「文衡，帮你做报告、查数据」/ C「有事问文衡」）
     ＋副行「出报告 · 查数据 · 核台账——期次我来认」；
   - 模式 chips：`出报告` `查数据` `看进展`（点击＝填入示例句，不直接发送）；
   - 示例胶囊 6 句：帮我做 9 月的报告 / 查一下化学的接近度 / 云南大学国际排名走势 /
     物理学的 1% 阈值是多少 / 数学什么时候进入前 1% / 202609 到哪一步了；
   - 大输入框；「本期任务」下移为「本期动态」一条。

### P1（一致性）

4. 陈列馆「回工作区」→ `/app/dialog/`，文案改「去问文衡」（两角色同）。
5. **样式卫生**：hover 补过渡（统一 150–300ms 变量）；focus-visible 补回（3 处）；
   可点 div 改 button（2 处）；时长 / 缓动收敛成 4–5 个命名常量。
6. 对话页「工作台▾」菜单按角色裁剪（操作员不列取数 / 运行档案——已实现，走查核对）。

### P2（打磨）

7. 陈列馆首页版式层级（hero → 馆藏 → 问文衡 → 页脚）与一次入场、错峰的动效编排。
8. 工作台 / 报告页密度与图表规范（编辑风：大标题、负空间、强对比）。
9. 全站键盘可达性与 aria 抽查（Tab 走查 + 焦点可见）。

## 5. 设计系统落点（沿用＋收敛）

- **方向**：编辑型学术风（ui-ux-pro-max「Exaggerated Minimalism」原则：大字号、强对比、大留白）；
  **保留**现有色板——云大绿 `--zhu #1A4B27`、纸色 `--bg #F4F3ED`、金 `--gold #B19A65`、朱砂强调。
- **字体**：标题衬线（`Noto Serif SC Variable`＋拉丁 Georgia 风）；界面无衬线；数字等宽（已有 `--mono`）。
- **对比度**：正文 `--ink #222B25` on `--bg #F4F3ED` 实测 ≥ 4.5:1（写进验收）。
- **动效**：微交互 150–300ms；页面级 ≤ 700ms；统一 3–5 个时长 + 2–3 条缓动；reduced-motion 保持。
- **图标**：SVG 线性（无 emoji）；可点元素 `cursor-pointer`。
