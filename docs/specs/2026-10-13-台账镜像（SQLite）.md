# spec：台账镜像（SQLite）——只读查询层（2026-10-13）

- **状态**：rick 已点头（2026-10-13：A 只读镜像 / 台账＋产物先做 / 作为 pi 内核的前置小票）→ ready-for-agent
- **票**：`.scratch/ledger-mirror/issues/01-台账镜像ETL.md`（本 spec 落它）、`02-引擎接镜像.md`（后）
- **红线前提**：唯一事实源仍是母本 xlsx（`src/ledger.py` 路径口径）；镜像**只读派生**，永不回写、永不进模型自由 SQL

## 决定（rick 2026-10-13）

1. **只读镜像，不换事实源**：xlsx 仍是唯一事实源；SQLite 是确定性、可重建的查询层。
2. **范围**：先台账（母本 → 长表 facts）；产物后议；**原始包（ESI/InCites）不入**。
3. **排期**：作为 pi 内核（对话层）的前置——先镜像 + 引擎接它（票 02），内核工具再接白名单视图。

## 架构

```
母本 xlsx ──(parse_ledger 现有确定性解析)──▶ ledger_long 口径的长表
                                              │
                              tools/build_ledger_mirror.py（确定性 ETL）
                                              ▼
                              out/_mirror/ledger.sqlite（只读消费）
                                facts(discipline, period, metric, source, value)
                                meta(schema_version, ledger_sha256, n_facts,
                                     periods, metrics, content_sha256)
```

- 长表口径**唯一实现**：`parse_ledger.long_table()`（与 `ledger_long.parquet` 同源同函数，不复制口径）。
- 切窗（ADR-0007）：镜像存全量，消费方按 `period <= 期次` 过滤——窗口在查询侧。
- 溯源：v1 到 **ETL 级**（值 ≡ `ledger_long` 口径、逐行可比对、可回放重建）；格级（sheet/row/col）后议。
- 路径唯一实现：`src/ledger.mirror_path()` → `out/_mirror/ledger.sqlite`。

## 三条边界（写死）

1. **数字只出自台账口径**：镜像行与 `ledger_long` 逐行等价；换算值（接近度等）仍走既有定义，不由 SQL 自由计算；
2. **模型不自由 SQL**：内核/引擎只选**白名单视图与参数**（视图清单在票 02 定）；
3. **单向 ETL**：db 永不回写母本；同母本（sha）→ 同内容（`content_sha256` 可校验）。

## 验证

- 单测（全注入）：合成长表 → 建库/读回/确定性（两次建库同 `content_sha256`）/空输入/缺库校验；
- 数据守卫集成：真母本 → 建到 tmp；行数 > 0；与 `out/<期次>/ledger_long.parquet` 按期次子集逐行相等（缺数据登记 skip）；
- `--verify`：库自校验 + 重新解析母本比对（确定性）。

## 范围外

- 原始包入库；产物入库（后议）；格级溯源；服务端会话库（独立，另案）；内核工具接视图（票 02）。
