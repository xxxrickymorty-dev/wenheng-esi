# spec：数据来源清单（sources 表）——文件级清单与指纹（2026-10-22）

- **状态**：rick 已点头方向（ADR-0012 决定 2「原始包不入库」）；本 spec 是实施口径
- **票**：ADR-0012 决定 2 / 7 / 11；与 `src/inventory.py`（件级盘点）的分工见决定 2
- **红线前提**：库只装**清单与指纹**，原始文件一个字节都不入库、一处都不改动

## 决定

1. **只装清单**：`sources` 表记路径、大小、修改时间、指纹。**原始文件不入库**（不复制、不压缩、
   不 parquet 化），ESI / InCites 原始包原地不动（ADR-0012 决定 2）。它是**控制面证据**：
   回答「这台机器上那份原始包是哪一份、有没有被人动过、换机拷全了没有」。
2. **与 `inventory.py` 分工，不重叠**：
   - `inventory.py`＝**件级**：某期四件（监测表 / ESI 包 / 论文清单 / InCites 快照）**齐不齐**，
     零副作用、每次现场看、**不读库**；服务端在用，本票不改它、也不让它改读库；
   - `sources`＝**文件级**：每个文件的路径 / 大小 / 修改时间 / 指纹，落库可对比。
   一句话：盘点判「件在不在」，清单判「文件是不是原来那一份」。
3. **扫描只读 + 报告落仓库**：对 `../数据与复现/` **只读**（只 `stat` 与读文件算指纹）；
   清单渲染件写 `out/_state/sources.md`，**不写回数据目录**（那里两份历史 md 清单保留不动）。
4. **增量指纹**：`size` + `mtime_ns` 与库里记的一致 → `--hash` 也**不重算**（InCites 9 GB，
   每次全量重算不可接受）；只有本工具记过且两项都没变才跳过，缺指纹的行照算。
   「大小与修改时间都没变、内容被换过」只有显式重算能发现——见 `check --hash`。
5. **迁移 004**：走既有 `MIGRATIONS` 递增（001/002/003 不动），`SCHEMA_VERSION=4`；
   读口不建库的纪律照旧（`sources_rows()` 库不存在 → `[]`）。

## 表结构

```sql
sources(kind, scope, rel_path, size, mtime_ns, sha256, scanned_at, payload,
        PRIMARY KEY(kind, scope, rel_path))            -- 迁移 004
```

- `kind` ∈ `esi` / `incites`；`scope`＝ESI 期次目录名（`202609`）或 InCites 快照目录名
  （`数据覆盖2016-2026.08.31`）；`rel_path` 相对 `../数据与复现/`（`ESI数据/202609/x.xlsx`）。
- 直接躺在 kind 根下的散件（`ESI数据/ESI总表模板.xlsx`、`incites/…zip`）`scope` 记 `_root`
  ——不属于任何期次/快照，但换机少一件同样要看得见。
- `sha256` 允许空串＝**只有元数据**（`--kind incites` 默认不指纹）；空串不是「没有这个文件」。
- `payload` 是保留位（将来深校验结论，如能否打开 / 表头指纹），当前写 `{}`。
- 目录本身不建行：只记文件。空目录＝0 个文件，`check` 仍把它判成「没了」。

## 工具 `tools/sources_index.py`

```powershell
uv run python tools\sources_index.py scan --kind esi --hash      # 元数据 + 全量指纹
uv run python tools\sources_index.py scan --kind incites         # 只元数据（9 GB 不算指纹）
uv run python tools\sources_index.py scan --kind all --scope 202609
uv run python tools\sources_index.py check --kind esi            # 新增 / 变了 / 没了
uv run python tools\sources_index.py check --hash                # 连指纹一起比（慢）
uv run python tools\sources_index.py export-md                   # → out/_state/sources.md
```

- `scan`：遍历 → 写/更新 → 逐 scope 打印文件数 / 大小 / 新增 / 更新 / 不变 / 算指纹；
  该 scope 里磁盘上已经没有的行**移除**（只动本次扫描过的 scope，逐条打印）。
- `check`：**纯读**（库不存在只提示、不建库、不删任何东西），三类逐条列出：
  新增（盘上有、库里没有）/ 变了（大小或修改时间不同；`--hash` 时连指纹不同也算）/ 没了。
- `export-md`：汇总表（每个 scope 的件数 / 大小 / 已算指纹数）+ 逐文件明细，写
  `out/_state/sources.md`（原子写）。

## 边界

1. **不碰原始数据**：不复制、不改名、不移动、不删除、不写回 `../数据与复现/`；
2. **不进请求路径**：本表不给 `/api/*`、不给报告出数；服务端要「件在不在」仍走 `inventory.py`；
3. **不展开压缩包**：`incites/数据覆盖2016-2026.08.31.zip` 记一条文件行，当作整体；
4. **不替代备份**：清单证明「这一份是哪一份」，丢了文件仍得从备份恢复。

## 验证

- 单测（全部 tmp 合成目录，不碰真实 9 GB）：扫描入库 / 重复扫描幂等 / `--hash` 在
  `size+mtime_ns` 未变时不重算（探针计数）/ 变了要重算 / `check` 三类判定 / `export-md` 内容 /
  库不存在时 `check` 不建库不删东西 / 003 库升级到 004 不丢数据；
- 真实数据（只读）：`--kind esi --hash`（47 期约 1672 文件）、`--kind incites`（只元数据），
  两次跑完再 `check` 应为「无变化」。
