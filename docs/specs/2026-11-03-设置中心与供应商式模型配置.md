## 病例与意图

- 问文衡顶栏（`wd-chat-top`）常驻「会话题＋设置」：标题与侧栏当前项重复（工程原则 7），
  设置是文字链太隐蔽；
- 身份行「admin · 管理员」重复声明（admin 即管理员）；
- 模型设置弹窗是自有发明（清单＋表单纵向滚），HanaAgent 已给成熟的「供应商」形制；
- 正文阅读字体只有一种，馆员无选择。

## 契约（四票）

### 票 1 顶栏撤销＋槽位条搬家（`web/src/dialog/DialogPage.tsx` + `dialog.css`）

- 删 `wd-chat-top` 整条 header（题、设置钮一起走；Ctrl+, 快捷键保留）；
- `SlotChip` 组（期次/意图/学科/指标）搬到线程区顶部的**槽位条**（`dlg-slotbar`）：
  **仅当 `hasSlots(active.slots)` 时渲染**，无槽位零占位；清槽交互不变。
- 「本期动态」等落地件不动；`docName` 仅作 `document.title`/aria 语义保留。

### 票 2 设置齿轮进侧栏＋角色声明撤销（`SideRail.tsx` + `lib/UserChip.tsx`）

- `UserChip` 身份行只渲染 `me.name`（title 悬停里保留「· 角色」说明与退出引导）；
- `SideRail` 增可选 prop `onSettings?: () => void`：传了才在身份行旁渲染齿轮图标钮
  （title「设置（Ctrl + ,）」，aria-label「设置」）；DialogPage 接线（人人可见——
  界面节人人可用，供应商节管理员才可写）；其他页面不接线（后续可选）。

### 票 3 设置弹窗改双节 hub（`ModelPanel.tsx` → 重构 + `dialog.css`）

- 弹窗左栏导航两项：**供应商** / **界面**（HanaAgent 式；默认落「供应商」）。
- **供应商节**（现 ModelSettings 内容重构为图五形制，语义不变）：
  - 顶部保留「服务器部署配置（.env）」只读行（当前/部署，改不了）；
  - 已注册供应商卡片：label＋model＋base_url＋key_hint＋note；动作 用这个/测一下/改/删
    （admin only；probe 结果行「✓ 通（N 个可用模型）（208 毫秒）」＝图五「模型信息」行的对应物）；
  - 新增/编辑表单字段序照图五：**名称 / Base URL / API Key（留空＝不改）/ 模型 / Headers
    （可选，多行 `K=V`）/ API 协议（select，单选 OpenAI Compatible）**；PRESETS 快捷片保留；
  - 非 admin：供应商节显示「要加或改模型，请让管理员来操作」，清单只读可见。
- **界面节**：**正文字体三选卡片**——衬线（默认，`--serif`）/ 非衬线（`--sans`）/ 楷体（`--kai`），
  各带一句短说明（照图四体例：适合正文阅读 / 更接近系统界面 / 手写书卷气）；
  选择存 `localStorage["wenheng.ui.font"]`，挂 `<html data-font="…">`；
  CSS：正文阅读面字体走新令牌 `--font-body`（缺省＝var(--serif)），`data-font` 切换该变量——
  **标题/品牌/印章等展示面保持 `--serif` 不动**（改的只是正文阅读字体）。
- 其他模型/工具模型（图五「其他模型」）**不做**——文衡无后台小模型任务面（防过度设计）。

### 票 4 后端 headers 支持（`src/ai/_models.py` + `_brain.py` + `server/app.py` probe）

- models.json 条目增可选 `headers: dict[str,str]`（≤8 条；键为合法 HTTP 头字符；
  前端 textarea `K=V` 每行一条解析成对象提交）；保存/读取 round-trip；
- `OpenAIBrain` 构造增 `extra_headers: dict | None`：与请求头合并；
  **opencode 内建会话头（按 base_url 规则）与 `Authorization`/`Content-Type` 不许被覆盖**
  （entry headers 只叠加自定义头）；
- probe 路由（`/api/models/test`）透传 headers（用表单 headers 探活）；
- `protocol` 字段：前端展示用，后端条目存 `"openai"` 缺省（不实现第二种协议）。
