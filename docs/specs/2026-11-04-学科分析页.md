# spec：左侧栏新增「学科分析」页（灵活报告的卡片式入口）

- **状态**：设计定稿（2026-11-04，rick 口谕：左栏新增「学科分析」＝原来的灵活报告；
  整页 22 个学科分析卡片，参考高校ESI报告板块版式；点卡片即生成该学科的灵活报告，
  成品如 `文衡灵活报告_202609_数学.html`）。
- **底座盘点（全部现成，零后端改动）**：
  - 意图唯一：`flexible/planner.py` `INTENTS = {"single_trend": "单学科分析报告"}`；
  - 生成：`runFlexibleStream(period, {intent:'single_trend', disc:<en>}, onEvent)`（NDJSON：
    plan/section/done）；同步口 `POST /flexible` 是 `@admin_route`；
  - 产物：`out/<期次>/flexible/single_trend/report.html`，公开读路由
    `GET /p/<期次>/flexible/single_trend/report.html`；已生成清单在
    `getFlexible(period).reports`；学科名单 `getFlexible(period).disciplines`（en/cn）；
  - 旧页 `Flexible.tsx` 已于 10-31 撤出导航（文件留存为死件，本票不接不删）。

## 契约（两票）

### 票 1 导航与路由（`SideRail.tsx` 常量 + `App.tsx`）

- `SIDE_NAV` 在「分析台」后插入 `{ key: 'discipline', label: '学科分析',
  href: '/app/?view=discipline', icon: <现有合适图标> }`（icons.tsx 里选，不新画）；
- `App.tsx`：`view === 'discipline'` 分支渲染 `DisciplinePage`（period 沿用页面的
  既有传参模式，rg 看-analysis 等页怎么拿期次）；active 高亮按 view 判定。

### 票 2 学科分析页（新文件 `web/src/DisciplinePage.tsx`，样式参考 schools 纸面）

- **页头**：眉标「学科分析」＋期次（来自 App 传入；只读展示即可）＋
  （当 `reports` 含 `single_trend` 时）「打开最近一份」文字链（新窗开 report.html）。
- **卡片网格**：`getFlexible(period).disciplines`（后端名单，en/cn；空则整页空态
  「本期还没有可分析的学科」）。22 张卡：中文名（衬线大字）＋英文名小字＋角标箭头；
  版式参考 schools 纸面语言（纸底、金线分隔、方角、无冗余小字——工程原则 7）。
- **点击卡片**（唯一动作）：
  - 同页**同时只允许一个生成任务**（busy 锁，其余卡禁用）；
  - 生成中该卡显示进度（「规划中…」→「第 N 节…」→收尾），`runFlexibleStream`；
  - `done` → 新窗 `window.open('/p/<period>/flexible/single_trend/report.html')`，
    卡面恢复并标「最近生成」（本地 state，不入库）；
  - `error` → 卡面显示错误一句（errorNote 口径）。
- **权限**：生成口后端 admin-only——`me.role !== 'admin'` 且该学科无已生成报告时，
  卡片点击提示「生成请找管理员」（hint，不禁用整页）；已生成报告的打开人人可用。
- 样式令牌用工作区系（--card/--panel/金线），**不引 schools 的 whs-\***（那是展陈面豁免）。

## 验收与测试

- `npx vitest run` 全绿＋新增最小用例（渲染出 22 卡、点卡走 stream mock、done 后
  window.open 被调、非 admin 未生成的提示）；
- `npm run build` 成功且 dist 入库；`uv run ruff check .` 兜底；
- UI 自查四点：导航项高亮正确；卡片网格 22 张；点卡生成进度可见且完成后新窗打开；
  非 admin 的提示正确。
