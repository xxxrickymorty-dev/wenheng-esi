## 问题

馆员现在**完全手工**：Excel 里算、Word 里画图写报告。整条链全靠人记——

- 数据**齐没齐**要自己记；缺哪件要自己找、去哪儿下；
- **期次**（"9 月的报告"到底哪期）也要自己记——**猜错就是整期返工**；
- 工作台是五个页面的菜单，先得知道"去哪一页、按什么顺序"。

而这三件事里，**没有一件需要人做**——它们都能被系统说清楚。

## 方案

一个**对话前门**（控制面）：说一句话 → **认期次**（先说出自己的理解）→ **盘点**（逐件）→ 缺就引导、齐就跳核对 → **触发流水线**（流式出稿）→ 三件套。

表格页（对勘本 / 红件清单 / 签单）**保留**，但从"必经"变"**被叫出来**"——工作台因此干净，而不是把关消失。

## 实现决策

- **控制面/证据面**（ADR-0006）：对话只做**指挥**——认期次、盘点、引导取数、触发流水线、解释；**不产生任何数字**。
- **期次解析**：解析出期次后**先说出理解**（「我按数据截至 2026-09 理解 → 202609」）；**该期数据未发布/不可用 → 停下反问**；**不支持"出稿月"说法**（期次只有一个含义）。
- **盘点**：按**必需件清单**逐件判——① 监测表 ② 顶尖论文清单 ③ ESI 原始包 ④ InCites 快照；**缺哪件说哪件**（判的是"件在不在"，不是"数对不对"）。
- **缺件引导（探测降级）**：本机有取数工具 → 驱动它（CDP 开真 Chrome），**登录那一步明说「这步得你来」**；没有 → 只报缺 + 给逐步引导。**取数链路只在有浏览器、有人在场的机器上成立**（公网服务器只能报缺）。
- **核对**：对话给「去核对 ▸」跳**表格页**；核完回对话继续（ADR-0004 的门由人签）。
- **出稿**：触发**既有**流水线；过程**流式**（复用 `flexible/report.py::generate_stream` 的 NDJSON：`status → plan → section×N → done`）；流式中输入框**原地变停止键**。
- **确认门只有一处**：覆盖已有产物——**行内二次确认**（按钮原地变「确认覆盖？」，3 秒退回，不做弹窗）+ **回滚到上一版**。并入台账由核对门兜。
- **留痕**：每轮对话 + 每次工具调用进 `ai_calls` / 运行档案；**不新开账本**。
- **槽位**：只记**期次 / 意图**（可显示、可清、可审计）；**不记自由上下文**。
- **权限**：沿用现有能力口的 `admin` 门。
- **意图范围**：接**查询类**（复用 `qa`）；**操作类**（改口径/重跑/撤签单）本批**不接**。
- **界面词**：一律 `GLOSSARY.md` 馆员话术（本期规划 / 数据校验 / 自动修复 / 需人工接手 / 盘点 / 核对 / 并入 / 签单）。
- **页面关系**：生成台/取数台/审核台/运行档案/陈列馆**保留路由**，顶栏「工作台 ▾」按需打开；分析台问答**并入前门**。
- **红线**（不变）：ADR-0005 三条 + 本 ADR-0006。

## 测试决策

- **好测试的标准**：只测**外部行为**——说了什么、回了什么、跳到哪、槽位是什么、有没有停；不测内部函数怎么写。
- **缝（优先级从高到低，共三条，不新增）**：
  1. **S1 `src/ai` 的能力口**（意图/期次解析的纯逻辑）——替身注入、零网络。先例：`tests/test_ai_*.py`（`ScriptedBrain` / `FailingBrain`）、`tests/test_flexible.py` 的规划用例。
  2. **S2 `server/app.py` 的新 `/api/dialog/*`**（对话轮次、盘点、槽位）——契约级。先例：`tests/test_api_flexible.py`、`tests/test_server_artifacts.py`。
  3. **S3 `web/src/lib/`**（槽位/期次解析纯函数）——vitest。先例：`web/src/lib/period.test.ts`、`status.test.ts`。
- **必须有的用例（外部行为）**：
  - 「做 9 月的报告」→ 回「按数据截至 2026-09 理解」+ 期次槽 = `202609`；
  - 该期未发布 → **停下**（不触发流水线）+ 给两条路；
  - 「做 7 月的报告」→ 盘点 4 件全 ✓ → 给「去核对」；
  - 「再出 202605 的」→ 槽位改期次、其余不变；
  - 覆盖已有产物 → **第一次点不执行**，第二次才执行；
  - 权限：非 admin 不可用。
- **UI 改动按 `web/AGENTS.md` 第 1 条**：先静态稿（已有五稿）→ 审核通过 → 再动 React。

## 范围外

- **操作类意图**（改口径 / 重跑 / 撤回签单 / 覆盖确认之外的写操作）——有副作用，下一批；
- **表格页本身的改动**（对勘本 / 红件清单 / 签单流程）；
- **多轮自由上下文**（只做槽位级记忆）；
- **槽位与对话的持久化**（进 URL / 进服务端）——P1，见 `UX-对话前门.md` §5；
- **窄屏适配**（桌面单用户）；
- **取数工具本身的改造**（只做探测与驱动，不改它）。
