## 背景与决定（rick 2026-10-13）

对话前门目前是纯规则（`modeled=False`），「最新的 / 指代」类问法靠规则补丁（票 10 只补了「最新」）。
rick 定：**把 pi 移入对话层当内核**——工具＝现有引擎、输出过盾、不进数据路径；
框架能帮的是「对话记忆 / 多步」那层体验，命根子（台账 / 盾 / 证据 / 期次 / 离线 / 留痕）仍自研。

## 架构

```
对话层（内核可缺席）
  规则 parse（确定性，永远第一道）
    ├─ 命中 → 原路（现有行为逐字保持）
    └─ 未命中且模型可用 → pi 内核补槽（只出槽位/措辞，零数字）
          工具（只读、零台账数值）：list_periods / scan_inventory / product_status
          输出校验：槽位 schema 白名单；出现数字 → 拒 → 回退规则
  离线（无 key / PROFILE=demo）→ 不启内核，纯规则（演示站完整可用）
```

- **模块**：`src/ai/_dialog_kernel.py`（模型出口仍只有 `src/ai` 一处）；
- **内核**：pi agent loop（Python 移植）——StreamFn 自供（真实＝OpenAI 兼容单发、复用 `_brain` 姿势；
  测试＝Scripted）；服务端仍无状态（历史随请求带上；pi 的会话树 / 压缩本阶段不用）；
- **工具白名单（阶段一，零台账数值）**：`list_periods`（known_periods）/ `scan_inventory`（既有盘点）/
  `product_status`（有无产物）；qa 引擎**仍由服务器按意图路由**（契约 #33 不变），不进内核工具面；
- **留痕**：每轮一条 `ai_calls`（capability=dialog，mode=model|rule|fallback）；
- **开关**：跟随 qa 能力开关（禁新旋钮，wayfinder 票 11 裁决）。

## 验收（04）

- 截图序列 + 指代序列（「那期」「上上期」「刚才那个」）实测；全量 pytest / e2e / check_web_app / ruff；
- **断网演示完整可用**（内核缺席＝规则版逐字不变）；运行档案可见 dialog 模型轮记录；
- 行为保持：规则命中路径与现状逐字一致（票 10 行为测试全过）。

## 风险与退路

- pi-agent-core 是社区移植（PyPI 0.1.1，Alpha、单维护者）→ **vendor 快照入库或锁版**（spike 定）；
  质量不足 → 备选 `yuramalna/pi-python`，或**同一接口换自研薄循环**（接口不变、实现可换）；
- async 与 FastAPI 的接法在 spike 里先验证。

## 范围外

- 数据路径的任何模型参与；服务端会话存储；自由上下文长期记忆（ADR-0006 维持）。
