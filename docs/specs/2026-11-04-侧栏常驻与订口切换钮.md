# spec：侧栏常驻（窄窗自动折叠）＋订口顶端切换钮

- **状态**：设计定稿（2026-11-04，rick 口谕：侧栏最短即折叠态，「继续缩小则消失」要治——
  参考图二 dsh 左上角切换钮，或让图三折叠轨常驻；本票两者合并落地）。
- **病灶**：折叠态（64px 图标轨）本就常驻可拖回；「消失」发生在窄窗口断点——
  ≤820px 把手 `display:none`（index.css:1703）、工作区 ≤900px `.app-shell` 转顶置块
  （index.css:1751 一带）、schools ≤960px 同类（schools.css）——窗口一窄，侧栏整条没了。
- **原则**：任何窗口宽度下侧栏**永不整条消失**；最窄即折叠轨（图三常驻）。

## 契约（两票）

### 票 1 窄窗自动折叠（`SideRail.tsx` 的 `useSideRail` + 三处 css 断点收口）

- `useSideRail` 增窄窗自适应：`matchMedia('(max-width: 900px)')` 监听——**从宽变窄跨过
  阈值且当前未折叠时自动置 `fold: true`**（不回写用户偏好判断：折叠后用户在窄窗展开
  就随他，不加反向强推）；≥901px 不做任何事（用户偏好说了算）。
- 三处断点改向：工作区 ≤900px 的「侧栏转顶置块」（`.app-shell{display:block}` /
  `.app-page-l{position:static…}` 段）、schools ≤960px 的同类段、≤820px 隐藏 `.app-grip`
  ——**全部改为「自动折叠后的图标轨」形态**：这些媒体段里不再隐藏/转置侧栏本体，
  只保留必要的间距收口；侧栏本体任何宽度都是左列。
- 断点统一 900px（schools 的 960 并入）。

### 票 2 订口顶端切换钮（`SideRail.tsx` + `index.css`/`window.css`/`schools.css`）

- 新增**唯一**切换控制位：一枚 28px 方钮**骑在订口金线顶端**（top:12px、水平中心对齐
  订口 `left: var(--app-lw)` + translateX(-50%)，z-index 高于把手与内容），描边＋深栏底，
  展开态箭头朝左、收起态朝右（icons.tsx 加或复用）；aria-label「收起侧栏/展开侧栏」、
  `aria-expanded`、aria-controls="app-nav"。
- 点击＝`toggle()`；与把手共存（钮在把手条顶层，点击归钮、拖拽归把手——pointer 事件
  不串）。
- **`.app-fold` 轨内旧钮删除**（SideRail 渲染段与对应 css 一并清理）——单一控制位，
  防双钮打架；折叠轨顶部只留品牌。
- 折叠轨观感照图三：品牌「文衡」＋图标导航＋身份行（Info/头像/齿轮），常驻不消失。

## 验收与测试

- `cd web && npx vitest run` 全绿；`npm run build` 成功且 dist 入库；
- UI 自查四点（文字描述）：①窗口缩到 ≤900px 侧栏自动折叠而非消失；②折叠轨在任意
  窗宽常驻；③订口顶端切换钮两态位置正确、点击展开/收起、不与把手拖拽打架；
  ④三入口（工作区/问文衡/schools）行为一致。

## 范围外

- 移动端 (<420px) 专项布局；陈列馆/shelf 自有壳不动；e2e（存量另案）；不推送远程。
