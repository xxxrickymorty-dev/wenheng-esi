# 前后端分工与接口契约（2026-09-23）

> rick 2026-09-23：前后端分离——**前端会话**只做前端，**后端会话**做后端。
> 本文件是两边**唯一需要严格对齐**的东西：边界 + 接口契约 + 联调方式 + 冲突预防。
> **改接口 = 改这个文件 + commit message 里写「契约变更」**，否则另一边会踩空。

---

## 0. 一句话边界

| | 前端会话（我） | 后端会话（你） |
|---|---|---|
| 目录 | `wenheng/web/**` | `wenheng/server/**`、`src/**`、`tools/**`、`tests/**` |
| 交付物 | React 视图 + G 陈列馆静态件 + **`web/dist`（构建产物入库）** | FastAPI 与流水线 + **`/app` 静态挂载（已就位）** |
| 管什么 | 视图 / 路由 / 状态 / 动效 / 组件 / 交互 / 可访问性 | **数据与口径** / 任务编排 / 审批落库 / 权限的真门 |

**两边只通过 `/api/*` 说话。** 前端不 import 后端代码、不读磁盘、不解析 docx；
后端不写前端文件、不改 `web/**`（唯一例外：`server/app.py` 里那两行 `/app` 挂载——**已就位，别动**）。

## 1. 谁碰什么（防冲突）

| 路径 | 归属 | 备注 |
|---|---|---|
| `web/**`（含 `public/shelf/`、`mockups/`、`dist/`） | **前端独有** | 后端不要动 |
| `server/**`、`src/**`、`tools/**`、`tests/**` | **后端独有** | 前端不要动 |
| `CONTEXT.md`、`GLOSSARY.md`、`AGENTS.md`、`docs/**` | 共享 | 改前先 `git status` 看有没有人在动 |
| `设计文档/**`（工作区根目录，另一个仓） | 前端（设计材料） | 后端一般不需要碰 |

**提交纪律**（两边一致）：只 `git add` 自己的文件；`git status` 里别人的改动不碰；做完就提交，不要攒。

## 2. 接口清单

### 2.1 已有（前端直接用，**别重建**）

| 端点 | 前端拿它干什么 |
|---|---|
| `GET /api/periods` | 管理工作台的期次列表（`period/label/signed/status/url`）；游客陈列馆改读安全 `data.js` 投影 |
| `GET /api/status` | 工作台「当前有没有任务在跑」；仅 admin 可读，返回 `{active: <任务 ID>\|null, last: {id,period}\|null}`，不返回完整任务记录、统计或服务器路径 |
| `GET /api/periods/{period}/artifacts` | 指定期次的可用产物；仅 admin 返回完整 `collect_period_artifacts` 列表 |
| `GET /api/periods/{period}/download/{key}` · `GET /api/jobs/{id}/download/{key}` | 附件仅 admin 可下载；`key=report` 时必须当前签发状态为 `signed`，未签发或签发已失效均拒绝。兼容下载路径执行相同报告门；日志包规则保持原样。 |
| `POST /api/jobs` | 生成台「一键生成」；已有运行任务时返回 409，且不会写入或覆盖 input 台账 |
| `GET /api/jobs/{id}` | 生成中 / 完成 / 失败的状态 |
| `GET /api/jobs/{id}/events` | **五步实时进度（SSE，已存在）** |
| `GET /api/jobs/{id}/artifacts` | 完成后的产物列表（报告 / 清单 / 图册 / CSV） |
| `GET /api/jobs/{id}/approval` | 签单状态 |
| `POST /api/jobs/{id}/rerun` | 失败后重跑 |
| `GET /api/forecast/meta` · `POST /api/forecast/run` | 预测模型选项与试跑 |
| `GET /healthz` | 探活 |

## 3. 契约纪律（两边都受，违反不会报错但会让另一边炸）

1. **所有 `/api/*` 必须登录保护**（`current_user(request)`）——`tests/test_stack_contract.py` 守着，别绕。
2. **GET 不改状态**；一切变更走 POST。
3. 🔴 **数字只来自后端**：前端**不换算、不聚合、不四舍五入、不补零**。展示什么就是接口给什么。
   （这是产品的根：每个数字都要能回溯到台账。前端多算一步，回溯链就断了。）
   **已知例外（仅此两处，2026-09-25 补记）**：`web/src/api.ts` 的 `humanSize()`
   把字节数显示成 `7.4 MB` / `651 KB`；`web/src/Forecast.tsx` 的 `fmtNum()`
   给 MAPE 这类数加千分位、固定小数位（后端没给的显示 `—`）。
   例外只作用于「怎么显示」——单位换算 / 小数位 / 千分位，**不许引入新的数**，
   不许回流到任何报告或对比；报告口径数字一律原样。新增例外必须写进本节。
4. **错误体统一**：`{error: string, hint?: string, missing?: [{sheet,column,note}]}`；HTTP 码语义固定（401 未登录 / 400 参数 / 409 状态冲突 / 500 服务端）。
5. **大件分页或懒加载**：大表 239 格、红件 704 行、图 99 张 —— 别在一个响应里全塞。**分页形状由后端定，前端适配**（我按你的形状改）。
6. **字段只增不改**：要改语义就新加字段，别复用旧名字（前端是按名字取的）。

## 4. 权限：前端隐藏 ≠ 后端不挡

- 前端按 `GET /api/me` 的 `role` 决定**显示什么**（游客看不到生成台/审核台）。
- **真正的门必须在后端**：游客直接 POST 生成、或直接 GET 红件清单，必须被 401/403 挡住。
- 前端隐藏只是"不打扰他"，不是安全措施——**别把安全性寄托在前端**。

### 7.3 预测模型选择持久化（T08a，2026-09-27）

- `GET` 与 `POST /api/periods/{period}/forecast-choice` 均仅管理员可用；未登录返回 401，游客返回 403。
- `{period}` 是用户发起任务时选中的请求/任务期次，不要求已有 `out/<period>/` 或派生产物。期次名原样保留，例如 `202605_复现`；不得去掉后缀。
- `POST` 的 JSON 顶层必须是对象，且 `choice` 为 `{路线: {学科: 模型名}}`。路线取自 `forecasting.ROUTES`，学科必须出现在 `forecasting.page_context()["subjects"]`（`ForecastMeta.subjects`）中，模型取自 `forecasting.MODEL_OPTIONS`（含 `recommended`、`all`）。无效 JSON、路线、路线值、学科或模型返回 400。`{"choice":{}}` 表示全用 V1 推荐，即使当前没有候选学科也可保存。
- 写入路径为 `out/_forecast_choices/<period>.json`，记录 `{choice, by, at}`。保存不会创建 `out/<period>/`，该配置目录也不作为可用期次列出。
- `GET` 优先读取新配置；新文件不存在时可读取旧路径 `out/<period>/forecast_choice.json`，只读且不迁移、不回写。两处都不存在时返回 `{period, choice:{}, by:"", at:""}`。
- 保存响应保留 `ok`、`saved`、`path`（相对路径）字段；`saved` 是已选学科数，嵌套形状可附 `saved_routes`。读回保留 `period`、`choice`、`by`、`at`。
