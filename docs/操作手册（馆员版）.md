# 文衡 · 每期出报告操作手册（馆员版）

## 一、每期只需三步（约 5 分钟 + 17 秒机器时间）

1. **取数贴表**：从 ESI 官网/InCites 取数，按老习惯贴进《云大全学科排名、阈值动态检测表.xlsx》
   （建议：把新一期列贴在对应工作表已有列后面；《千分之一被引阈值》表请**按列追加、不要覆盖**历史列）
2. **放入输入目录**：把填好的台账另存为 `wenheng\input\<期次>\监测表.xlsx`
   例：202609 期 → `wenheng\input\202609\监测表.xlsx`
3. **双击 `一键出报告.bat`**：等屏幕跑完（约 17 秒），自动给出：
   - ✅ 全绿 = 数据完整，报告已生成
   - ❌ FAIL = 某处没贴全（会写明缺哪张表哪一列），补上再跑一次即可

## 二、结果在哪、拿到什么

输出目录：`wenheng\out\<期次>\`

| 文件 | 用途 |
|---|---|
| 报告初稿_<期次>（试排）.docx | 主体交付：打开复核 → 补【手工：…】→ 交签单 |
| 红色件清单.md | 签单依据：本期改了哪些格子/文字/图，各自来自哪 |
| 对照差异报告_<期次>回测.md | （仅回测时）与人工原件的逐格差异 |
| 预测回测报告.md | 预测模型精度（MAPE） |
| table2.csv | 大表数据（Excel 可开，备查） |

## 三、报告里还需要人工的少数位置

打开初稿后搜索 **【手工：** ，共 6 类：
ESI 发布日期、当期全球机构总数、去年同期升幅%、学院贡献度、省级高校总数、目录页码。
（另外：省表中非云大高校数据、顶尖论文清单，按既往流程人工贴入。）

## 四、什么时候需要找开发（不用每次找）

- 台账**新增工作表/列**或改了表头写法 → 解析器要先适配（把新台账发来即可）
- 想让图表换样式（配色/图例/范围）→ 改 `charts.py`
- 想启用本地小模型润色文字 → 见 `docs/本地模型接入方案.md`

## 五、小故障排查

| 现象 | 处理 |
|---|---|
| 断言 FAIL：宽表 XX 含期次 202609（缺列/缺数） | 台账里该表还没贴 202609 的数据，补上 |
| 断言 FAIL：千分之一阈值含 202609 | 《千分之一被引阈值》表没贴当期列 |
| 双击闪退 | 用命令行运行 `wenheng` 目录里的 `.venv\Scripts\python.exe src\run_latest.py` 看报错 |
| 想重跑 | 直接再双击一次（可重复运行，不产生副作用） |
