# 文衡 · 每期出报告操作手册（馆员版）

## 一、每期只需三步（下载与核验由机器跑；您只做：登录一次、核对一眼、点三次按钮）

1. **取数**：工作区 → 出报告 ①「取数并核验」→「开始取数」。**系统会自动打开取数专用浏览器**——首次在里面登录 ESI / InCites 一次（凭证由浏览器自己记住），之后点「重新检查」即可。
   系统自动按 9 组下载约 64 份文件，并**逐份核验**（下载完成 ≠ 台账已更新）。某组还缺几份时，点那一组的「补下这一组」只补没下到的。
2. **核对并并入**：「待核对」出现后，看一眼「本期新增列核对表」（或打开当期核对副本）→
   点「核对无误 · 并入台账」。系统只写当期列：**历史一字不动**，写前自动备份，写后逐格核对。
3. **生成**：回生成台点「生成报告」（或双击 `一键出报告.bat`，约 17 秒），自动给出：
   - ✅ 全绿 = 数据完整，报告已生成
   - ❌ FAIL = 会写明缺哪张表哪一列（多为台账还没并入当期数据），回取数台处理后再跑一次即可

## 二、结果在哪、拿到什么

输出目录：`wenheng\out\<期次>\`

| 文件 | 用途 |
|---|---|
| 报告初稿_<期次>（试排）.docx | 主体交付：打开复核 → 补【手工：…】→ 交签单 |
| 红色件清单.md | 签单依据：本期改了哪些格子/文字/图，各自来自哪 |
| 对照差异报告_<期次>回测.md | （仅回测时）与人工原件的逐格差异 |
| 预测回测报告.md | 预测模型精度（MAPE） |
| table2.csv | 大表数据（Excel 可开，备查） |

## 三、报告里还需要人工的少数位置

打开初稿后搜索 **【手工：** ，共 6 类：
ESI 发布日期、当期全球机构总数、去年同期升幅%、学院贡献度、省级高校总数、目录页码。
（另外：省表中非云大高校数据、顶尖论文清单，按既往流程人工贴入。）

## 四、什么时候需要找开发（不用每次找）

- 台账**新增工作表/列**或改了表头写法 → 解析器要先适配（把新台账发来即可）
- 想让图表换样式（配色/图例/范围）→ 改 `charts.py`
- 想启用本地小模型润色文字 → 见 `docs/本地模型接入方案.md`

## 五、小故障排查

| 现象 | 处理 |
|---|---|
| 取数台某组还缺几份 | 点那一组的「补下这一组」——只补没下到的，已下过的不重复下载（**已并入台账也能补**） |
| 想整期重取一遍（含已并入的期次） | 点「**重新取这一期**」——同样只补没下到的文件；**已并入的台账不受影响**（采集与入库是两条线，互不锁死） |
| 取数提示浏览器未连接 / 未登录 | 系统**会自动打开取数专用浏览器**；在里面登录 ESI、InCites 一次，再点「重新检查」（首次用必须登一次） |
| 断言 FAIL：宽表 XX 含期次 202609（缺列/缺数） | 台账里该表还没并入当期数据：回取数台核对并入（或按老办法补表） |
| 断言 FAIL：千分之一阈值含 202609 | 同上：《千分之一被引阈值》缺当期列 |
| 双击闪退 | 用命令行运行 `wenheng` 目录里的 `uv run python src\run_latest.py` 看报错 |
| 想重跑 | 直接再双击一次（可重复运行，不产生副作用） |
