# ADR-0017 问数台为唯一自然语言取数入口：跨口径组合（提案 v1）

- 状态：**提案 v1**（2026-11-06；目标由 rick 拍定；未实现；待拍板项见文末）
- 关系：**取代 ADR-0016 的宿主与分期**——0016 把 DAG 架在问文衡台账段
  （`_plan` → `flexible/queries` → `_evidence`），本 ADR 改架在**问数线**
  （`aiqa_engine` → `aiqa.sqlite` → `render_row`）。0016 的 v1 审计对照与
  复审记录**保留为历史**（那六条发现仍然有效，只是宿主换了）；0016 里
  「决定 4 零数字面」「决定 9 回落语义」两条口径被本 ADR 继承并改写到问数侧。
- 红线：运行期 LLM 不进数据路径——本 ADR 反而把它加硬：问数答案正文由
  **模板**拼（`render_row`，零模型），模型只出规格，且只在规划轮出现。
- 关系（其余）：不修订 ADR-0006（对话是控制面）、不修订 ADR-0008
  （对话层只填槽位）；ADR-0015 的三库分工不变（问数库仍是「云大指标
  事实查询面，可确定性重建」）。

## 目标（rick 2026-11-06 定）

1. **问数台成为唯一的自然语言取数入口**——答案里的数字只从
   `aiqa_engine.execute` 出来；
2. **支持跨口径组合**——同一问里同时出现学科口径、省域高校口径、
   全校口径、报告大表口径。

## 背景（先核事实，再谈方案）

**今天有两条自然语言取数缝**，而且都在跑：

| 缝 | 取数 | 答案 | 代码 |
|---|---|---|---|
| 问文衡·台账段 | `_plan` → `queries.execute` → `_evidence` | **模型写正文**（走盾） | `_qa.py:132-164` |
| 问数直答 | `aiqa_engine.plan` → `execute` → `render_row` | **模板拼句子**（零模型） | `_dialog.py:863-937` |

前门已经把问数句式**默认**直调引擎（`_dialog.py:1034-1039`），但两类仍
被排除、交给问文衡：① 多期序列问法 `_SERIES_SPAN`（`_dialog.py:110`）；
② `qa_direct=False` 时整套回落模型作答（`_dialog.py:1040-1044`）。
→「唯一入口」要收的正是这两类，加上台账段那半边。

**为什么跨口径只能在问数线做（这条是本 ADR 的立项根据）**：
问数库是**五面一库**，键各不相同——

| 表 | 维度 | 覆盖面 | 备注 |
|---|---|---|---|
| `facts` | 学科 × 期次 × 指标 | 台账全史 | `aiqa_db.py:85-94` |
| `report_table2` | 学科 × 期次 × 11 列 | **多期**（扫 `out/*/table2.csv`） | `aiqa_db.py:97-104`、`:441` |
| `report_overview` | 期次 × 键值 | 多期 | `:107-112` |
| `province_fact` | 高校 × 期次 × 指标 | **当期快照**（不跨期累积） | `:123-132` |
| `ynd_rank_series` | 期次 × 3 列 | 历史序列 | `:134-140` |

台账段的 `LedgerView` 只有「学科 × 指标」一维（`datasource.py:144-167`），
**没有省域、没有概述、没有大表列**——「化学 × 昆工 × 云大排名」这类问题
在台账段是结构上做不到，不是登记一个算子能做到的。

**问数线今天的缺口（一期要补的）**：

1. **零模型**：`aiqa_engine` 明说「本模块不直接调模型」（`:7`），
   `qa_direct` 也标 `modeled=False`（`_specs.py:40-43`）——自然语言变体覆盖不了；
2. **缺表**：没有 events 表 → 「化学什么时候进的 ESI 前 1%」在问数线答不了
   （台账段有，`queries.events` + `_evidence._events`）；
3. **缺算子**：没有 `delta`（两期差）、没有 `anomaly`（相邻期越界）；
4. **pointer 到行不到格**：`_qa_pointer` 里 `table2` 只到 period
   （`_dialog.py:853-854`），「每个数字能回格」比台账段低一档；
5. **模型面别名不全**：问数指标名带阿拉伯数字（`thr_1pct` / `thr_1permille` /
   `permille_rank` / `rank_pct` / `n_inst_1pct`），而 `metric_face.FACE` 的
   `model` 列不覆盖问数独有指标（`metric_face.py:58-68`）——直接进 prompt 会被
   数字盾打穿。
6. **旗舰例子其实不需要 DAG**：1‰ 差距有两条便宜解法——加一列
   （先例 `compute.py:105` 的 `thr_1pct_gap`，落库三处 `aiqa_db.py:101/254/476`
   ＋ `_TABLE2_COLS`）或读 `facts` 两指标相减。**DAG 不为这个例子而生**。

**留痕生命周期（决定「记在哪」的关键事实）**：`qa_log` 是问数库唯一
运行期可写表（`aiqa_db.py:142`），但 `build()` 是**全新重建 + `os.replace`**
（`aiqa_db.py:464-520`），**不保留旧 `qa_log`** → 行为账会随库重建清空；
`ai_calls.jsonl` 是追加型（`_record.py:2`）。所以审计/回放不能只落 `qa_log`。

## 决定

### 一期：把入口、能力、模型面补齐（不做 DAG）

1. **入口收敛（唯一入口）**：前门凡「取数问法」一律走问数——**含**多期序列
   问法（`_SERIES_SPAN` 那条排除撤掉）与带问数槽的追问；`qa_direct` 关闭时
   **该能力关闭**，不回落模型作答（否则入口不唯一，见待拍板 2）。
   问文衡台账段**冻结**：不再扩展、不再修组合题，留作过渡（见待拍板 1）。
2. **能力补齐（对齐台账段今天的覆盖面）**：新增 `events` 表（ETL 自台账
   《学科进入时间》/ `entered_1pct`）＋ `events` 算子；新增 `delta`
   （两期差/变化率）算子。`anomaly` 同口径可做，排二期。
3. **旗舰例子的正解＝加列 + 跨期列算子**：`thr_1permille_gap` 进
   `compute.build_table2` → `table2.csv` → `aiqa_db`（建表/写入/列白名单三处）
   → `_TABLE2_COLS` 加一行；新增 `column_series`（大表某列跨期序列）。
   这条**不需要 DAG**，一期即可答「化学近三期 1‰ 差距在拉大还是缩小」。
4. **问数模型规划器**（新缝，位置在 `src/ai`）：
   - 落在 `src/ai`（如 `_aqa_plan.py`），`aiqa_engine` **保持零模型**——
     反向 import 会成环（`_dialog.py:879-880` 是懒加载调引擎的）；
   - 经 `_attempt.attempt(anchored=False)`（复用盾 + 校验 + 记录边界）；
   - 输出**规格列表**（不是 DAG）：算子 ∈ 问数闭集，参数来自库内枚举；
   - **期次不进模型面**（沿用 0016 决定 4 / `_plan.py:103-126` 口径），
     「最近 N 期」的 N 为系统侧**命名档**且档名不含阿拉伯数字；
   - **新建问数无数字模型面别名表**：扩 `metric_face.FACE` 一列（唯一口径
     表不另起一张），补齐问数独有指标的别名；中文名不进模型面；
   - 越权键 / 未知算子 / 档位越界 / 带数字 → **整份回落规则规划器**；
     `strict`（供应商开启）下模型失败抛 `AIRequiredError` 不回落（同
     `_plan.py:238-247`、`_attempt.strict_enabled()`）。
5. **pointer 逐格化**：执行行 → 逐格来源指针（facts 到 学科/指标/期次；
   `report_table2` 到 期次/学科/列；province 到 期次/高校/指标；ynd 到 期次/列）。
   这是「每个数字能回格」在问数线的落点，也是台账段冻结后来源索引的替代面。
6. **留痕分工（两条账，两种生命周期）**：
   - **审计/回放**：模型轮与规格全文 → `ai_calls.jsonl`（新增 capability id），
     追加型、不随重建丢；
   - **行为账**：执行结果 → `qa_log`（既有，不承载审计）。
7. **离线不变**：无 key / 演示锁 → 规则规划器逐字不变（今天问数永远规则）；
   开关跟随 `qa_direct`，不新增部署旋钮。

### 二期（条件触发）：DAG = 跨口径组合

8. **规格语法升 DAG**：节点＝一期已登记的算子（闭集，不扩）；边＝**同键引用**；
   派生节点（`diff` / `ratio` / `base`）必须两输入同键。
9. **跨口径的键约束写死**（防止 DAG 承诺做不出来的事）：

   | 组合 | 共同键 | 允许 |
   |---|---|---|
   | `facts` ↔ `report_table2` | (学科, 期次) | **可派生** |
   | 学科口径 ↔ 云大排名 / 概述 | 仅 (期次) | 只可**并排**成多段，不算术 |
   | 学科口径 ↔ 省域高校 | **无** | 只可并排，不派生 |
   | 省域高校（当期快照） | (高校, 期次) | 只当期，不做序列 |

10. **形状集＝问数现有渲染模板**：派生节点必须落进已有形状之一，落不进则拒
    （0016 决定 6 的「登记成本从类型降到形状」在问数线同样成立）。
11. **规划依据（cite）**：`anomaly` / `scope` 类节点默认 `cite=no`；
    **值不得并入可引用节点的输出（不参与算术/聚合），但可作选择集/过滤条件**
    且该依赖留痕——比 0016 决定 5 的「一律不得消费」松一格，否则这些节点
    在图里没有角色。
12. **校验在引擎侧**：拓扑/成环/键对齐/档位/白名单全在引擎校验，模型面不校验。
13. **回放**：规格全文进 `ai_calls`；回放＝**直跑 `aiqa_engine.execute`**，不重调
    模型；判据＝同库（同 `content_sha256`）同规格同输出。

## 为什么（对 0016 的三处改口）

1. **宿主换线**：0016 的宿主（台账段）**结构上没有**省域/概述/大表列三面，
   「跨口径组合」在那里不是登记一个算子能解决的——所以不是 0016 写得不够好，
   是宿主选错了。
2. **立项理由换掉**：0016 写「组合型问题答不了」，旗舰例子却能用「加列 +
   `column_series`」一条便宜路解决。本 ADR 把理由改成**跨口径组合**：
   学科 × 省域 × 全校 × 大表列，这才是台账段做不到、问数线独有的事。
3. **一期不做 DAG**：先用一期把入口、能力、模型面补齐（这三件是「唯一入口」
   的直接前提，与 DAG 无关）；DAG 只在跨口径需求实测高频时启动——0016 v2
   「由使用数据触发」的纪律保留。

## 代价（知情接受）

- **模型面净新增一条**：问数线今天零模型，等于新造第二份规划器（与 `_plan`
  并存）。不能复用 `_plan` 的原因：宿主不同（`LedgerView` vs sqlite）、算子表
  不同（8 vs 7）、别名面不同；可复用的是 `_attempt` / `_shield` / `_record`。
- **别名表扩共享表**：扩 `metric_face.FACE` 会影响 `_plan` / `_qa` / `aiqa_engine`
  三方（C5 收敛的好处是只有一处，代价是改一处要跑三方用例）。
- **pointer 与形状面变化**：逐格 pointer 会改问数答案的行-源对应；派生节点要
  挤进既有模板。
- **`qa_log` 不持久**：行为账随库重建清空——审计只能靠 `ai_calls`，这一点要
  在运行档案界面上如实。
- **产品取舍**：问数答案从「模型写的一段话」变成「模板拼的句子」——
  「唯一入口」的代价是答案形态统一但更硬；这是要 rick 认的取舍。
- **金标成本**：问数原先「规则天然确定性」，加模型后必须新增
  「模型缺席逐字不变」断面 + 每算子至少一例 + 跨口径组合例。

## 明确不做

- 不引入任意代码执行；不让模型写正文（问数正文继续模板拼）；
- 不做跨口径算术（无共同键即不派生，只并排）；
- 不新开账本、不新增部署旋钮；
- 不在一期拆掉台账段（冻结即可，答案形态迁移单独立项）；
- 不在跨口径需求实测前上 DAG。

## 待拍板（两条，决定一期大小）

1. **台账段：冻结还是立即改为消费问数结果？**
   - 冻结（建议）：一期小，问文衡答案形态不变，风险最低；
   - 立即改：一期大一倍（要换 `_evidence` 的证据面与编号来源），但「取数
     入口唯一」当场成立。
2. **`qa_direct` 关闭的语义**：关＝问数入口关闭（不回落模型作答，入口保持唯一）
   还是保持现状（回落问文衡，入口暂时不唯一）？
