## 目标（rick 2026-11-06 定；已拍板）

1. **问数台成为唯一的自然语言取数入口**——答案里的数字只从 `aiqa_engine.execute` 出来；
2. **支持跨口径组合**——同一问里同时出现学科口径、省域高校口径、全校口径、报告大表口径；
3. **不保留「查 Excel」的第二形式**——问答侧只读问数 sqlite。

> 三条已拍板；如何落到代码（一期哪些、二期哪些、收口怎么收）是本案待实现的方案，未接受。

## 背景（先核事实，再谈方案）

**今天有两条自然语言取数缝**，而且都在跑：

| 缝 | 取数 | 数据面 | 答案 | 代码 |
|---|---|---|---|---|
| 问文衡·台账段 | `_plan` → `queries.execute` → `_evidence` | parquet **或 Excel 母本** | **模型写正文**（走盾） | `_qa.py:121-164` |
| 问数直答 | `aiqa_engine.plan` → `execute` → `render_row` | **只 sqlite** | **模板拼句子**（零模型） | `_dialog.py:863-937` |

前门已把问数句式**默认**直调引擎（`_dialog.py:1034-1039`），但两类仍被排除、
交给问文衡：① 多期序列问法 `_SERIES_SPAN`（`_dialog.py:110`，**撤除条件见决定 1**）；
② `qa_direct=False` 时整套回落模型作答（`_dialog.py:1040-1044`）。

**问答侧今天真的会读 Excel**：`_qa._view_for`（`_qa.py:84-118`）本期 parquet 在
就用 `DataSource`，parquet 不在就**现场直读母本 Excel**（`WorkbookView`，
`flexible/workbook.py:32`）——`queries.py:22` 的数据面协议也明写这两种适配器。
这就是要退场的「查 Excel 形式」（硬断言 (c) 成立）。

**只认 sqlite 不破「母本唯一事实源」**：问数库的上游**主要是**流水线产物——
`ledger_long.parquet`（`:203-231`）、`table2.csv`（`:234-258`）、`overview_facts.json`、
`province.parquet`、`ynd_rank.parquet`；`build()` 还会读母本 xlsx 只为算 `ledger_sha256`
（`aiqa_db.py:406`、`:497-498`，只哈希不取值）——「上游全是产物」不精确，修正如上。
Excel 母本仍在**流水线解析期**读一次，只是不再出现在问答链路上。数据链变成：
母本 Excel → 流水线 → parquet/csv → sqlite → 问答。

**为什么跨口径只能在问数线做（立项根据）**：问数库是**五面一库**，键各不相同——

| 表 | 维度 | 覆盖面 | 备注 |
|---|---|---|---|
| `facts` | 学科 × 期次 × 指标 | 台账全史 | `aiqa_db.py:85-94` |
| `report_table2` | 学科 × 期次 × 11 列 | **多期**（扫 `out/*/table2.csv`） | `aiqa_db.py:97-104`、`:441` |
| `report_overview` | 期次 × 键值 | 多期 | `:107-112` |
| `province_fact` | 高校 × 期次 × 指标 | **当期快照**（不跨期累积） | `:123-132` |
| `ynd_rank_series` | 期次 × 3 列 | 历史序列 | `:134-140` |

台账段的 `LedgerView` 只有「学科 × 指标」一维（`datasource.py:144-167`），**没有
省域、没有概述、没有大表列**——「化学 × 昆工 × 云大排名」这类问题在台账段是
结构上做不到，不是登记一个算子能做到的。

**问数线今天的缺口（一期要补的）**：

1. **零模型**：`aiqa_engine` 明说「本模块不直接调模型」（`:7`），`qa_direct` 也标
   `modeled=False`（`_specs.py:40-43`）——自然语言变体覆盖不了；
2. **缺表**：没有 events 表 → 「化学什么时候进的 ESI 前 1%」在问数线答不了；
3. **缺算子**：没有 `delta`（两期差）、没有 `anomaly`（相邻期越界）；
4. **pointer 到行不到格**：`_qa_pointer` 里 `table2` 只到 period（`_dialog.py:853-854`）；
5. **模型面别名不全**：问数指标名带阿拉伯数字的，facts 侧真缺 `model` 别名的是
   `rank` / `rank_pct` / `n_inst_1pct` / `avg_cites` / `permille_rank`
   （`metric_face.py:58-68`，这 5 个 `model:""`）；`thr_1pct` / `thr_1permille` 其实是
   `report_table2` 的**列名**（`aiqa_engine.py:42-43`），facts 侧叫 `threshold_1pct` /
   `threshold_1permille` 且**已有** `model` 别名（`threshold` / `threshold_permille`，
   `metric_face.py:38-43`）。ADR v2 把两套命名空间混在一起，已更正。
   ⚠ **数据面未定**：`avg_cites`、`permille_rank` 不在 `dim_metric`（`aiqa_db.py:425`
   只从 `flexible.datasource.METRICS` 建字典，实测库 13 指标里没有这两个），执行时会以
   「不在白名单」被拒（`aiqa_engine.py:364-366`）——扩别名前须先定这两项从哪张表来
   （属未实现设计，先立项不先编数）；
6. **旗舰例子其实不需要 DAG**：1‰ 差距用「加派生列（在 `aiqa_db` ETL／参数化 SQL 里由
   `total_cites − thr_1permille` 出）+ `column_series`」就能答。**DAG 不为这个例子而生**。

**留痕生命周期（决定「记在哪」的关键事实）**：`qa_log` 是问数库唯一运行期可写表
（`aiqa_db.py:143`，注释行 `:142`），但 `build()` 是**全新重建 + `os.replace`**（`:464-520`），
**不保留旧 `qa_log`** → 行为账随库重建清空（硬断言 (a) 成立）；`ai_calls.jsonl` 是追加型（`_record.py:2`）。

## 决定

### 一期：入口、数据面、能力、模型面（不做 DAG）

1. **入口收敛（已拍板）**：前门凡「取数问法」一律走问数——**含**多期序列问法
   （`_SERIES_SPAN` 那条排除撤掉）与带问数槽的追问；`qa_direct` 关闭＝**该能力
   关闭**：关闭点共**四处**，少一处「入口关闭」就是假的——
   - `_dialog.py:1034-1039`（`qa_direct` 门）；
   - `_dialog.py:1040-1044`（`unclear`→`query` 提升）；
   - `_dialog.py:1090-1097`（`query` 分支，经 `_query_reply` 路由）；
   - `server/routes/dialog.py:417-427`（服务器再 `ai.run("qa", …)` 由模型作答）。
   改出「问数入口已关闭」说明（复用 `qa_direct` 的 `no_data_notice`；其现有文案
   「这句交给常规问答」要改，见决定 8）。
   ⚠ **撤 `_SERIES_SPAN` 前先给 `series` 加窗口参数**（沿用台账段 `span=recent`＝
   截至当期最后 6 期的口径，`_qa.py:150-154`），否则「最近六期怎么变的」会被答成
   「全期序列 + 最新值」——与决定 3「对齐台账段今天的覆盖面」冲突（R4）；参数不
   就绪则**保留反问**，别用「能力倒退」换「入口唯一」。
   **问文衡台账段冻结**：不再扩展；问答路径不再调用 `_qa._ledger_evidence`，
   **且模型工具环一起关**（见决定 2）。
2. **取数只认问数 sqlite（已拍板：问答侧不读 Excel）**：
   - 数字唯一来源＝`aiqa_db.connect_ro` → `aiqa_engine.execute`；
   - 问答路径**不得**现场直读 Excel 母本（`_qa._view_for` 的 `WorkbookView` 支路退场），
     也**不得**直接 `queries.execute` 读 parquet（`DataSource` 属**产线内部**：
     `build_aiqa_db` 的 ETL 与灵活报告第二产线，问答侧从不构造它——见 E8）；
   - **补两条漏网**（v2 决定 2 只点了 `_ledger_evidence`，按字面施工仍会回落）：
     ① `_qa.py:830-839` 的模型工具环（`_qa_tools` / `_qa_executor`，`view` 可能就是
     `WorkbookView`/Excel 或 `DataSource`/parquet，模型可自主拉台账数字）——台账段
     冻结须连这层一起关；② `_qa.py:435-438` 的 `_disc_rows` 直接 `open(out/<期次>/table2.csv)`，
     学科直答段数字由此而来、指针写 `table2.csv#…`——这条不走 `execute`，须显式收；
   - 上游缺 parquet → sqlite `facts` 空 → 问答**显式不可用**（不回落 Excel、不改读 parquet、
     不编数），说明文案走「该期取数不可用」口径；
   - `WorkbookView` / `flexible/workbook.py` **不删**——灵活报告第二产线仍可用，
     只是退问答。
   - ⚠「台账段冻结」的准确含义＝**代码保留、问答路径退场、模型工具环一起关**（不是
     「继续用但不扩展」）：`_qa._ledger_evidence` 与 `_qa_tools`/`_qa_executor` 不再出现在
     问答链路；若还要它作答，其数字也须经问数（答案形态迁移单独立项，二期）。
   - R1（文档同步）：问答侧取消回落，但代码/票据里还有 5 处写同一回落——`.scratch/llm-arch/issues/01-引擎扩op.md`、`src/flexible/datasource.py:8-10`/`:148-149`、`src/flexible/workbook.py:2-11`、`src/ai/_qa.py:26-27`、`src/flexible/queries.py:22`——收口实现票须一并改，否则与「问答侧取消回落」直接矛盾。
3. **能力补齐（对齐台账段今天的覆盖面，否则「唯一入口」＝能力倒退）**：新增
   `events` 表（ETL 自台账《学科进入时间》/ `entered_1pct`）＋ `events` 算子；
   新增 `delta`（两期差/变化率）算子；`anomaly` 同口径可做，排二期。
4. **旗舰例子的正解＝派生列 + 跨期列算子**：`thr_1permille_gap` 由 `total_cites`
   − `thr_1permille` 在 **`aiqa_db` ETL／参数化 SQL 里派生**（`total_cites` 与
   `thr_1permille` 都已在 `report_table2`），**`table2.csv` 一个字节不动**；新增
   `column_series`（大表某列跨期序列）答「化学近三期 1‰ 差距在拉大还是缩小」。
   ——**不采用**「加第 12 列进 `table2.csv`」：那是 11 列 / 242 格书面契约的局部破坏，
   牵连 `test_pipeline_smoke.py:51`、`agent/audit.py`、`tools/verify_report_cells.py`、
   `server/workbench.py`、`tools/method_boundary.py` 等多处登记面（R3）；若未来坚持进
   大表，须把上述契约与登记面一并写进改动清单，本次不做。
5. **问数模型规划器**（新缝，位置在 `src/ai`）：
   - 落在 `src/ai`（如 `_aqa_plan.py`），`aiqa_engine` **保持零模型**——反向
     import 会成环（`_dialog.py:879-880` 是懒加载调引擎的）；
   - 经 `_attempt.attempt(anchored=False)`（复用盾 + 校验 + 记录边界）；
   - 输出**规格列表**（不是 DAG）：算子 ∈ 问数闭集，参数取自库内枚举；
   - **期次不进模型面**（沿用 0016 决定 4 / `_plan.py:103-126` 口径）；「最近 N 期」
     的 N 为系统侧**命名档**且档名不含阿拉伯数字；
   - **新建问数无数字模型面别名单**：扩 `metric_face.FACE` 一列（唯一口径表不另起
     一张），补齐问数独有指标（先解决 `rank`/`rank_pct`/`n_inst_1pct` 三个已有白名单的，
     `avg_cites`/`permille_rank` 待决定 5 的数据面后再补）；中文名不进模型面；

6. **pointer 逐格化**：执行行 → 逐格来源指针（facts 到 学科/指标/期次；
   `report_table2` 到 期次/学科/列；province 到 期次/高校/指标；ynd 到 期次/列）。

   `qa_log`（既有，不承载审计）。
8. **冻结后的收口计划（不做会烂在仓库里）**：

### 二期（条件触发）：DAG = 跨口径组合

10. **规格语法升 DAG**：节点＝一期已登记的算子（闭集，不扩）；边＝**同键引用**；
    派生节点（`diff` / `ratio` / `base`）必须两输入同键。
11. **跨口径的键约束写死**（防止 DAG 承诺做不出来的事）：

    | 组合 | 共同键 | 允许 |
    |---|---|---|
    | `facts` ↔ `report_table2` | (学科, 期次) | **可派生** |
    | 学科口径 ↔ 云大排名 / 概述 | 仅 (期次) | 只可**并排**成多段，不算术 |
    | 学科口径 ↔ 省域高校 | **无** | 只可并排，不派生 |
    | 省域高校（当期快照） | (高校, 期次) | 只当期，不做序列 |

12. **形状集＝问数现有渲染模板**：派生节点必须落进已有形状之一，落不进则拒。
13. **规划依据（cite）**：`anomaly` / `scope` 类节点默认 `cite=no`；**值不得并入
    可引用节点的输出（不参与算术/聚合），但可作选择集/过滤条件**且该依赖留痕——
    比 0016 决定 5 的「一律不得消费」松一格，否则这些节点在图里没有角色。
14. **校验在引擎侧**：拓扑/成环/键对齐/档位/白名单全在引擎校验，模型面不校验。
15. **回放**：规格全文进 `ai_calls`；回放＝**直跑 `aiqa_engine.execute`**，不重调
    模型；判据＝同库（同 `content_sha256`）同规格同输出。

## 为什么

1. **宿主换线**：0016 的宿主（台账段）结构上没有省域/概述/大表列三面，「跨口径
   组合」在那里不是登记一个算子能解决的——不是 0016 写得不够好，是宿主选错了。
2. **立项理由换掉**：0016 写「组合型问题答不了」，旗舰例子却能用「派生列 +
   `column_series`」便宜路解决。本 ADR 把理由改成**跨口径组合**：学科 × 省域 ×
   全校 × 大表列，这才是台账段做不到、问数线独有的事。
3. **一期不做 DAG**：先把入口、数据面、能力、模型面补齐（「唯一入口」的直接前提，
   与 DAG 无关）；DAG 只在跨口径需求实测高频时启动。
4. **为什么砍掉 Excel 支路**：问答侧留两条数据面，等于同一个问题可能有两种答案
   （sqlite 与母本直读各自的口径、各自的新旧），且 Excel 现场解析是最慢最脏的一条；
   「问数」在产品上的语义是**查库**，不是**查表**。砍掉后链路唯一、可回放、可重建。

## 代价（知情接受）

- **缺 parquet 时问答从「能答」变「不可用」**：今天 Excel 母本兜得住，今后不兜。
  知情接受——宁可显式不可用，也不要两条数据面出两种答案；前提是流水线常跑、
  `build_aiqa_db` 常新（运维纪律要在部署文档写明）。
- **模型面净新增一条**：等于新造第二份规划器（与 `_plan` 并存到二期删除）。不能
  复用 `_plan` 的原因：宿主不同（`LedgerView` vs sqlite）、算子表不同（8 vs 7）、
  别名面不同；可复用的是 `_attempt` / `_shield` / `_record`。
- **死代码与口径同步**：`_plan.plan` 变死代码、`queries.py:2` 的「唯一入口」措辞要改、
  `qa_direct` 文案要改、R1 的 5 处回落表述要改——文档/测试同步是实际工作量（见决定 8）。
- **既有用例会破**：`qa_direct=False` 回落的断言、台账段相关用例、`_view_for`
  有关用例都要改（实现票里逐条列）；其中 `_view_for`/`_aiqa_reply` 的 `except` 会吞
  异常，验收判据不能用「打成抛错」桩（见验收 1，R2）。
- **别名表扩共享表**：扩 `metric_face.FACE` 影响 `_plan` / `_qa` / `aiqa_engine` 三方；
  `avg_cites`/`permille_rank` 须先定数据面再补别名（见背景 5）。
- **`qa_log` 不持久**：行为账随库重建清空；审计只能靠 `ai_calls`，运行档案要如实。
- **产品取舍**：答案从「模型写的一段话」变成「模板拼的句子」——形态统一但更硬。
- **`series` 窗口参数**：撤 `_SERIES_SPAN` 前须先给问数 `series` 加 `span=recent`
  6 期口径（R4），否则唯一入口＝能力倒退；参数就绪前保留反问。

## 明确不做

- 不引入任意代码执行；不让模型写正文（问数正文继续模板拼）；
- 不做跨口径算术（无共同键即不派生，只并排）；
- **不在问答侧保留第二条数据面**（Excel 支路退场，不做「先 sqlite 再 Excel」双路）；
- 不删 `WorkbookView` / `queries` / `_evidence`（灵活报告与评测仍在用）；
- **不新增 `table2.csv` 第 12 列**——旗舰例子走派生列，11 列 / 242 格契约不动（R3）；
- 不新开账本、不新增部署旋钮；
- 不在一期拆台账段渲染（冻结即可，答案形态迁移单独立项）；
- 不在跨口径需求实测前上 DAG；
- **不改动 `src/` 任何产线代码**——本案全部为文档与方案收敛，落地走实现票。

## 验收（一期可执行）

1. **问答路径零 Excel、零 parquet 直读**（本版重写判据，原「打成抛错」桩不可证伪，R2）：
   用**计数断言**——`_qa._view_for` 调用 **0 次**、`WorkbookView.__init__` 与
   `DataSource.__init__` 各 **0 次**；**正控**：在旧行为（未收口）下同一驱动问句计数
   **>0**，证明计数确实能拦得住；**指定驱动问句**：例「查一下 202607 那期」（不带指标、
   过不了 1034 的门但会进 `_qa.build`，正好打到两条漏网）——断言这些调用为 0。
   不依赖「抛错被吞」式桩。
2. **`qa_direct=False` 入口真的关**：用例「查一下化学的接近度」既不调模型
   （断言 `ai_calls` 无新增）也**不进 `qa`**（断言 `server/routes/dialog.py` 不再
   `ai.run("qa", …)`）；出「问数入口已关闭」说明。四处处处改到，否则此条必不过。
3. **台账段冻结**：问答路径不调用 `_qa._ledger_evidence`（monkeypatch 计数为 0），
   且 `_qa_tools` / `_qa_executor` 工具环在问答链路计数为 0（决定 2 漏网一并关）。
4. **缺 parquet 断面**：sqlite `facts` 空 → 「该期取数不可用」，不回落 Excel、不编数。
5. `uv run python tools\build_aiqa_db.py --verify` → 计数与 meta 一致。
6. 演示锁断面：问数全量金问集在「无 key / demo」下答案与今日**逐字一致**。
7. 新增能力用例：`events` / `delta` / `column_series` 各一组；旗舰例子（1‰ 差距
   近三期）走**派生列**出正确方向（符号口径先定：按接近度变化，由引擎侧确定性比较，
   不在 `render_row` 随手减，R5）。
8. pointer 逐格：抽 10 条答案，每个数字都能回 `aiqa.sqlite` 对应表对应格。
9. 模型缺席 / 模型成功 / 盾拒 / 越权键 / 带数字 五种规划面走查。
10. `uv run python -m pytest -m "slow or not slow"` → EXIT 0；`ruff check .` 全过；
    文档计数用 `tools/doc_counts.py` 同步（不手写用例数）。
