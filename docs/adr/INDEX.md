## 状态枚举（5 值，固定）

| 值 | 含义 |
|---|---|
| `已接受` | rick 已拍板、落地或待落地的现行决定（「已采纳」并入此值） |
| `提案` | 方案未拍板、未落地，仅记录思路与权衡 |
| `待确认` | 起草完毕、待 rick 拍板；**无拍板记录不得作现行引用**（未生效） |
| `已取代` | 被后续 ADR 取代，仅作历史存档 |
| `已修订` | 主体有效，部分条款被后续 ADR 修订（修订面以修订件为准） |

## 读法

1. 读 ADR 先看本 INDEX 的「状态」与「是否现行有效」；**被取代 / 待确认（未生效）/ 提案**的「决定」节只作历史或待办，不当现行依据。
2. 引用继承条款时方向要对：**现行件引历史件**（如 0017 引 0016 的零数字面 / cite / 回落语义），不反过来让历史件主张自己为现行。
3. 数字口径（ESI 期数 / InCites 快照数 / 槽位数 / 用例数）以单一来源为准，冲突须注明统计时点；ADR 不手抄用例数（用 `tools/doc_counts.py`）。
