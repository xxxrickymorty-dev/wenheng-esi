# 对话层可模型辅助：只填槽位、零数字、全程留痕

- **状态**：已接受（rick 2026-10-13 拍板；同日实现并验证——spec
  `docs/specs/2026-10-13-对话层内核（pi）.md`、票集 `.scratch/duihua-neihe/`）
- **关系**：**修订 ADR-0006**（对话是控制面，表格是证据面）的决定 2 / 6 / 7——
  「对话只做指挥、不产生任何数字」「全量留痕」「槽位级记忆」全部继续有效；
  本次只开一个口子：**听懂**这一层可以模型辅助（补槽），模型不产生数字、不写正文。
  ADR-0005（自主放「决策与校验」、不放「算数与事实」）与数据路径红线原样成立。

## 背景

- 对话前门是纯规则（`modeled=False`）：期次识别确定性优先，票 10 只给「最新的」打了补丁；
  「那期 / 上上期 / 刚才那个」这类指代与多步问法，规则很难穷举，馆员的自然说法会被
  反问挡住（2026-10-13 rick 截图实问暴露「最新的」复读死循环，同族问题）。
- rick 定：**把 pi（agent loop 的 Python 移植）移入对话层当内核**——工具＝现有引擎、
  输出过盾、不进数据路径；框架帮的是「对话记忆 / 多步」那层体验，命根子（台账 / 盾 /
  证据 / 期次 / 离线 / 留痕）仍自研。
- spike（票 01）：候选 `pi-agent-core`（PyPI，Alpha、单维护者）vs `yuramalna/pi-python`；
  选前者——StreamFn 自供、依赖面最小（仅 pydantic）、体量小，**vendor 快照**入库
  （`src/_vendor/pi_agent_core/`，来源/版本/许可/哈希见其 README；不动 pyproject/uv.lock/venv）。

## 决定

1. **规则永远第一道**：`parse` 与全部既有分支（显式期次 / 出稿月纠正 / 「最新的」/
   槽位带过轮 / 短应诺）原样优先，命中即原路；内核只在**兜底点**被叫到——
   句内没有期次、有对话上文、规则未命中（`_dialog.build` 一处）。
2. **模型只填槽位，零数字**：内核输出 schema 白名单 `{period, intent}`；`period` 必须
   来自 `payload.periods`（已知期次）或空串；`intent` ∈ {""、"出报告"}；出现其他数字、
   白名单外键、越界期次 → 一律拒（`brain_error:bad_response`）→ 回退规则。
3. **离线回落规则**：无 key / `WENHENG_AI_PROFILE=demo` / qa 能力开关关闭 /
   vendored 包缺席 → 内核不启、零外发，演示站纯规则**逐字不变**（断网完整可用）。
4. **工具白名单（只读、零台账数值）**：`list_periods`（payload.periods）/
   `scan_inventory`（既有盘点注入，只报件在不在）/ `product_status`（有无产物）；
   qa 引擎仍由服务器按意图路由（契约 #33 不变），不进内核工具面。
5. **开关跟随 qa 能力**（禁新旋钮，wayfinder 票 11 裁决）：qa 关＝内核关；
   模型有无仍由部署配置决定。
6. **全程留痕**：每轮一条 `ai_calls`（capability=dialog；mode=model|fallback|rule 如实；
   失败带回落原因码；egress / elapsed 如实）。`Answer.mode` 仍是 `rule`——正文始终
   规则拼装（徽标不冒充模型版），模型参与度看记录面。
7. **接口可换**：内核唯一出口 `_dialog_kernel.assist()`；质量不足时同一接口换自研薄循环
   （实现可换、调用方不动）。

## 为什么

- 期次猜错＝整期返工（ADR-0006 的静默传下去风险），所以确定性解析不能被替换——
  内核只做「规则听不懂时」的兜底，且输出被 schema 白名单与「零数字」卡死，
  最坏情况（模型胡说）也只是回退到原规则。
- 内核跑的是**只读工具**（件在不在、有没有产物、期次表），没有任何台账数值出口；
  运行期 LLM 不进数据路径的红线在结构上仍成立。
- 留痕先行：模型辅助轮进同一条 `ai_calls` 账本（不新开账本），运行档案可见。

## 代价（知情接受）

- 指代轮多一次模型往返（只在部署配了 key 时发生；失败/超时即回落，不堵对话）；
- pi-agent-core 是 Alpha 社区移植——vendor 快照锁版（升级＝重拷 + 重跑 Scripted 测试）；
- 内核补出的期次仍可能错（模型理解错）——对冲手段不变：**说出解释**（报告路回显
  「数据截至…」）、**坏输出即拒**、**全量留痕可回放**。
