# 灵活报告判断草稿与待审线：判断放给模型、界线画在版面上

- **状态**：已接受（rick 2026-10-14 拍板；grilling 两轮定稿，同日进实施）
- **关系**：修订 `评审文档/19-双模式报告设计方案v1` §D 的「专业判断绝不出现」口径；
  是 ADR-0005「自主放决策与校验、不放算数与事实」在灵活报告**正文**上的落法。

## 背景

- 旧口径下灵活报告正文有四道闸：四、五节只出规则假设 + `【手工：】`空位；
  `opinion.guard` 见「建议/应当/必须」即报警；报告自检 `no_professional_judgement` 把判断措辞当失败；
  正文三处重复声明（"非结论""本产线不生成专业判断"等）。
- 实际产物观感：大量部位"没有输出"（空位），重复声明稀释信任。而灵活报告本就是
  **内部参考件、非报送件**（不进签单、不对外），馆员清楚其来历、会自行复核。
- ADR-0005 的原则本就把「判断」划在自主面——旧口径是比 0005 更紧的特例，不是它的必然推论。

## 决定

1. **判断节创写**：四、五节由写作位从「全篇事实摘要（带溯源）+ 该主题查询结果」写出判断草稿；
   `【手工：】`空位降为写作位不可用/判不过时的回退安全值（描述节回退规则稿不变）。
2. **待审线**：需馆员拍板的句子呈现为「待审句」（细下划线标记）；模型自标 + 兜底词表
   （建议|应当|必须|值得|需要|优先，可配置）补标。自检口径从"出现判断词即失败"改为
   **"判断句未带标记即失败"**。
3. **声明只留一处**：报告头部为唯一说明处，正文与附录不再重复（"提示过的不再提示第二遍"）。
   「待验证假设 / 可验证方式」正文退役；核验走「关于本稿 · 来源链」与逐格溯源工具。
4. **不做闭环**：灵活报告不进签单流程；系统不记「已核对/已拍板」状态——拍板在线下完成。
5. **写深与创写的分工**：描述节把规则稿写深（升降方向由规则锚死，模型只负责"写得好"）；
   判断节由模型创写。数字仍走占位盾（一个不多、一个不少）——模型输出里依然没有数字物种。
6. **术语**：内部代码与文档统一叫「写作位」；「成文 Agent」保留为材料叙事名（三个 Agent 口径），
   界面仍一律禁用（见 GLOSSARY）。

## 代价（知情接受）

- 出稿引入慢写成本：写作位用 reasoner 级模型（本机 1–3 分钟/份）；演示站仍规则后端，评委看已出稿。
- 判断草稿的措辞质量进入馆员视野——由待审线与线下拍板兜住，不再靠"不写"回避。
- `评审文档/19` §D/§E（含评委答词）需同步修订——修订稿由本仓起草、rick 审定后材料侧引用。

## 红线不动

- 模型输出里没有数字（占位盾 + 来源链）；复刻报告一个字节不变；图表轴范围仍由数据决定。
