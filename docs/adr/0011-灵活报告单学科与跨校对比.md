# ADR-0011 灵活报告收敛为「单学科分析 + 指定对标高校」

- 状态：已采纳（2026-10-20，rick 定）
- 取代：`cross_compare`（多学科横向对比）作为灵活报告意图
- 关联：`评审文档/19-双模式报告设计方案v1.1（权威口径）-20261015.md`、
  `docs/adr/0009-灵活报告判断草稿边界.md`、参考件
  `植物与动物学分析/2016-2026植物与动物学学科分析.pdf`

## 背景

灵活报告最初按两个意图落地：`single_trend`（单学科趋势）与
`cross_compare`（22 学科横向对比）。2026-10-20 用户澄清：**灵活报告只需要
单学科分析报告；跨校对比的对象是“同一学科下的其他高校”，不是“校内其他学科”。**
参考件是《我校植物与动物学学科 2016—2026 学科发展态势分析报告》。

## 决定

1. **只保留一个意图**：单学科分析报告。删除 `cross_compare` 及其
   `_cross_sections`、图型编排、前端第二栏与相关测试。
2. **报告五节**（先做数据能支撑的部分）：
   1. 学科概况（当期落点 + 关键指标）
   2. 学术影响力（CNCI、篇均被引走势）
   3. 学科排名（国际/国内位次与百分位）
   4. 跨校对比（同一学科，云南大学 vs 用户指定高校）
   5. 学科展望（被引频次与 1‰ 阈值；规则推演，标注非预测模型）
   另按 ADR-0009 保留末尾「判断草稿」（成因研判 / 建议事项），不计入五节。
3. **对标高校每次由用户指定**（中文或英文校名），不设默认名单。
   未指定时不出跨校对比数据，正文明确提示「本次未指定对标高校」。
4. **数据来源**（只读，运行期不调 LLM）：
   - 跨校：`数据与复现/ESI数据/<期次>/<学科英文名>.xlsx`
     （全球位次、发文、总被引、篇均被引、顶尖论文）；有归档总表时优先用
     `_归档统一命名/<期次>/<期次>ESI总表模板.xlsx`（带中文校名）。
   - 其余四节：沿用台账 parquet 与既有查询层。
5. **不做**（本期明确不做）：参考件的期刊分区、微观主题、学者、合作四章。
   这些需要 WoS 论文级导出，当前流水线尚未接入；等数据接入后另立 ADR。

## 后果

- 旧意图产物 `out/*/flexible/cross_compare/` 保留为历史件，不再新增；
  前端不再展示该栏。
- 灵活报告的标题统一为「〈学科〉学科分析报告（〈期次标签〉）」。
- 生成入口必须能接收 `peers`（对标高校名单）；未传时按第 3 条处理。
- 测试需覆盖：校名解析、跨校取数、五节结构、`cross_compare` 不再被接受。
