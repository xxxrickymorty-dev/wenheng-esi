# ADR-0016 问数算子 DAG：放开组合、封闭算子

- 状态：**提案**（2026-11-05 草拟，待 rick 拍板；未实现）
- 关系：延续 ADR-0005（自主放「决策与校验」、不放「算数与事实」）、
  ADR-0006（对话是控制面、表格是证据面）、ADR-0008（模型辅助只填槽位、
  零数字）；**不修订**任何既有决定，只在问数线上加一层。
- 红线：运行期 LLM 不进数据路径——本 ADR 不碰这条，模型仍然零数字。

## 背景

问数（`src/aiqa_engine.py`）与灵活报告查询层（`src/flexible/queries.py`）
目前是 **kind 白名单**：一个问题类型注册一个 kind + 一个证据渲染器，
问题**实例**（任意期次 × 学科 × 指标）开放组合，问题**类型**封闭。
先例：compare 当初不在名单，支持它＝显式登记 kind + 补证据渲染器。

这带来一个真实代价：**组合型问题答不了**。例如
「化学近三期的 1‰ 阈值差距在拉大还是缩小？」——不是任何已注册 kind，
但拆开就是 `series → delta → trend`，每一步都是引擎里已有的确定性算子。
每来一类这样的问题都要走一轮「登记 kind + 写渲染器」，穷尽规则不可持续。

另一头是 pi 式「四个工具写代码」的完全自由方案，本 ADR 明确否决，
理由长在验收判据上：

1. **坏答案的形态**：白名单拒答是响的（「不在白名单」）；任意代码
   「跑通了但口径错了」（分母取错、期次串了）是**哑的**——演示现场
   评委看到的是一个理直气壮的错数字。
2. **确定性是验收命令**：`verify_demo_run.py` 要求重跑当期流水线
   产物确定性一致；任意代码生成做不到。
3. **数字夹带实测会发生**：现有数字白名单 veto（`monitor/insight.py`、
   `ai/_writer`）就是为此存在的。

## 决定（提案内容）

**放开组合，不放开原语**：模型的工作从「选一个预制 kind」升级为
「用封闭算子拼一张执行图（DAG）」，执行、取值、渲染全部仍归引擎。

1. **算子集封闭**：只有引擎登记过的确定性算子可入图
   （`series` / `at` / `compare` / `delta` / `anomaly` / `events` /
   `scope` 等，起步以 `flexible/queries.py` 现有六个为底，
   按需增补 `trend` 这类纯方向判断）。算子登记制不变——
   每个算子带参数 schema 与确定性实现。
2. **模型产物＝DAG 规格 JSON**（节点表 + 边表 + 每节点参数），
   过 schema 校验后才执行。以下情形一律**当场拒、回落规则规划器**：
   算子不在白名单、参数越界（学科/期次/指标不在名单）、图成环、
   节点缺输入、输出形状没有对应证据渲染器。
3. **执行确定性**：逐节点按图求值，参数化、只读视图，
   取值仍只出台账（与 `aiqa_engine` 同一条缝）；每个节点的
   输入引用与输出值留痕，逐节点可核。
4. **渲染仍走证据面**：图中叶子节点的结果形状必须映射到
   **已注册的证据渲染器**；没有渲染器的形状不进回答。
   即：组合放开的是**查询**，不是**呈现**。
5. **离线回落**：无 key / 能力开关关闭 → 模型不画图，
   现行规则规划器原样兜底（演示站逐字不变）。
6. **留痕进同一条账本**：`ai_calls` 记 capability、mode
   （dag / fallback / rule 如实）、DAG 规格全文与拒收原因码。

## 为什么

- 组合型问题不再需要逐个登记 kind：算子在库里，模型负责拼，
  「差距在拉大还是缩小」这类问题从「不可答」变成「画一张三节点图」。
- 坏 DAG 全部是**响的失败**：不合法当场拒，最坏回落现状；
  没有新增任何一条「跑通但错」的静默路径。
- 与既有分层同构：ADR-0008 让模型填 `{period, intent}` 槽位，
  本 ADR 让模型填图结构——放的是**结构自由度**，数字路径纹丝不动。

## 代价（知情接受）

- 算子集本身是新工作量：每个算子的参数 schema、边界行为、
  与证据渲染器的对接都要设计与测试；
- DAG 可能**合法但无意义**（图合法、渲染器在、但答非所问）——
  对冲靠「说出理解」（回答首句回显模型拼的图意）+ 留痕可回放；
- 模型可能填错参数（理解错学科/期次）——对冲不变：
  参数校验拒越界、回显确认、`ai_calls` 可追责。

## 明确不做

- 不引入任意代码执行（不做 pi 式「写代码跑数」）；
- 不碰报告初稿数据路径——本层只服务问数 / 对比线；
- 不新增部署旋钮：开关跟随既有 qa 能力（ADR-0008 第 5 条同款）。
