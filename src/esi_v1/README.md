# ESI 双路线模型 V1

本目录是 `ESI_Workflow_Model_V1_Handoff` 的站内调用副本。核心模型与固定配置来自已校验的 V1.0 交接包；`model_core_v1.py` 只把配置导入改成了包内相对导入，数值逻辑未改。

交接包原始 SHA-256：`config_v1.py` 为 `22975016…60e96`，`model_core_v1.py` 为 `a23e2829…4da55`。测试会还原相对导入这一处差异后复核两份校验和，防止 V1 被无意改写。

固定口径：

- 双月数据，季节周期 6；
- 初始训练窗口 30 期；
- 历史拟合 MAPE 从第 7 期开始；
- 扩展窗口一步滚动回测；
- SARIMA 从 3 × 4 候选池中仅用初始 30 期按 AIC 选阶，之后固定阶数；
- 经验贝叶斯状态空间模型使用 `local linear trend + seasonal(6)`，初始 30 期估计方差参数，之后固定参数；
- 输入使用四项指标同时齐备的公共期次，以复现 2026-07 V1 基线。

`service.py` 在核心的一步预测外增加网页所需的多期递推：每次预测一期，把预测值追加到序列后重新拟合下一期；SARIMA 阶数和状态空间方差参数仍保持冻结。V1 正式验证范围仍是一步预测，网页会把长期过线结果标为监测信号。

数据只从 `out/<期次>/` 的只读派生产物装载，不写台账、报告或 PostgreSQL。
已确认的输入修正也设有闸门：经济与商业 2020-03 总被引必须为 31；若派生产物回退为其他值，模块会停止并提示修正台账、重跑流水线，不会在内存中静默替换。

站点入口与接口：

- `GET /forecast`：登录后的预测工作台；
- `GET /api/forecast/meta`：返回当前数据期次、学科、路线与模型选项；
- `POST /api/forecast/run`：请求体形如 `{"subject":"物理学","task":"citation","model":"all","horizon":18}`。`task` 取 `citation` 或 `rank`，`model` 可取 `recommended`、`all` 或一个固定模型全名，`horizon` 为 1–24。

三个入口均沿用现有会话登录。预测计算放在线程池中执行，避免阻塞同一 FastAPI 进程里的页面与探活请求。
