# 文衡 5180 前端重新设计 · 轮次 01 设计说明

**目标**：给 5180 实验站（`wenheng/frontend/`）做一轮视觉重设计。硬约束一条——主色为绿色；重点在用户交互体验与视觉动效。
**范围决定**：令牌层优先（改 `ws.css` 令牌与共享组件，18 个视图一起变）；动效强度＝克制但有来路（三处基本动效，150–300ms，悬停位移 ≤2px）。
**本轮交付**：三个方向的首屏小样 + 风格对比页。**尚未落 React**，等选定后再动代码。

## 用户任务与主动作

使用者是云南大学图书馆馆员：非技术、每两月用一次、要求数字精确。来首屏是为了**看本期读数 → 走完三步 → 签单下载**。首屏属于「来看内容、处理对象」一类，不放口号，也不放解释这个页面是干什么的段落。

关键状态：未取数 / 取数中 / 已出稿待签单 / 已签发。本轮三个小样画的是**已出稿待签单**——信息量最大，也是落印那一刻所在。

设备约束：桌面 1440×900 为主，馆员在台式机上用。

## 共用地基

**品类**：机构内部数据工作台。地板是「侧栏 + 顶栏 + 卡片网格」，本轮三个方向里两个打破了它。

**标杆**：Linear 首页（真实截图 `tmp/bench-linear/page.png`），对着图拆出 6 条。
- 沿用：产品实样进首屏、两级按钮（实底主操作／文字级次操作）、1px 极低对比描边。
- 换掉：深色底（在否决清单，且档案室是白天看纸）、700 粗体（馆员读惯宋体）、几何无衬线（已有 Noto Serif SC 且中文长文更易读）。

**调性五刻度**：安静偏活一档 · 精致（4px 网格、字号至多 6 档、色相至多 3 个）· 中低密度 · 中偏重 · 庄重。

**共用样例**：三份小样用同一份真实数据，全部来自 `wenheng/out/202609/overview_facts.json` 与 202601–202609 五期台账，无一个编造数字。

## 本轮做了什么

- 三个方向各一份 1440×900 单文件 HTML 首屏，零外部依赖，双击即开。
- 每个方向自己看、自己截图自查过，改掉重叠、裁切和留白断裂后重截。
- 风格对比页 `style-explorer.html`（含方向卡字段，可并排/单张/实际尺寸看，点「选择」复制选择句）。
- 动效手感调参台 `动效手感调参台.html`：两个滑块（刚度 k、阻尼 c）实时改一条弹簧曲线，三个演示件（按钮／面板／印章）按同一条曲线动；带三个方向的预设和重置。用来把「手感」从形容词变成可挑的参数。

## 本轮没做什么

- **没落 React**。选定方向后才改 `ws.css` 与组件。
- **没做交互和动效**。方向探索阶段的三个首屏按规矩只做静态主状态。
- **没做响应式**。只做 1440×900 桌面。
- **没派独立评审**。方向探索阶段的对比页先交给人挑，不派评审者。

## 待决 / 遗留

1. **A 的印章对比度 1.61:1 不达标**——这是有意的：尚未签发，所以印是淡的；签单后才落成一枚实印。选定 A 时它会在签单态变实，同时改用 3px 粗描边保证实态达标。
2. **B 要破「零圆角」规矩**。4px 圆角的理由是纸卡材质；选 B 就要改 `frontend/README.md` 规矩 2。
3. **三份小样都不含取数台的轮询态、失败态、空态**。选定后再补状态图。
4. 陈列馆（`view=shelf`）是脱离壳独占整幅的特例，本轮没进候选。

# 轮次 01 落地记录（rick 选定 A 排字房之后）

## 决策

方向＝**A 排字房**；范围＝令牌层优先；动效＝克制但有来路。
落地方式：派出两个子代理分头做，文件集严格不重叠（一个独占共享样式，一个独占器件与组件），避免同时改同一份 CSS。

## 落了什么

**色板**：纸 `#F4F1E7`／主色青瓷绿 `#1F5B4A`／深 `#143D31`／选中底 `#E3EDE7`／描边 `#C9D8CE`／墨 `#1A211E`／朱砂 `#A8332A`（只给印章）。

- `ws.css` 蓝场 `--field*` 换青瓷绿；`--tool*` 一并收进同族深浅档——**蓝色彻底退场**，不是蓝绿对调。
- 修掉 `[data-palette="green"]` 把 `--zhu` 翻成蓝的坑，任何 palette 下强调色都是绿。
- `index.css` 的 `@theme` 里 sea/pine 合并为同一套；`spread.css`、`pano.css` 两套独立色板收齐。
- 器件与组件里的 `sea-*`（蓝）全转 `pine-*`，过时的「蓝为场·绿为器」注释一并改掉。

**动效**（弹簧 380/14 ≈ 250ms）：

- `index.html` 补了先于渲染的内联脚本加 `html.m-js`。**`motion.ts` 整层入场动效此前因为缺这个类，完全不显形**——接线接了，视觉上等于零。这是本次最值钱的一处。
- 入场单条 500ms → 260ms，错峰 70ms → 60ms（封顶 5 项），总长 560ms ≤ 600ms。
- 主操作按下缩到 .97，120ms 生效回弹。
- 期次切换＝纸面从右抽出（不交叉淡化，内容没换只换了期）；签单落章＝**纸沉 2px 回弹**，印章落、纸受力。
- 四件器件全部动起来：翻牌 `rotateX` 250ms、水位涨落 500ms、落章与钤印压落 500ms。

**可读性**：深绿底上的浅字原是 `text-pine-50/80` 这类半透明，有效亮度被拉低到 3.77:1。改成**层次靠色阶不靠透明度**（主要 `pine-50` 实色、次要 `pine-100` 实色），lab 三屏 22 处不达标降到 0。

## 遗留一处有意不达标

**pending 橡皮戳（还没盖的那枚）`opacity:.62`，字 3.09:1。** 它是「未盖章」这个状态的表达，盖了才会实；参考稿 A 里未签发的印同样是淡的（`.seal{opacity:.28}`）。不修。

## 没做

- **18 个视图没有逐个精修**（范围定的是令牌层优先，全站一起变，不是每屏深耕）。
- **报告屏 `Report.tsx` 没接「换期抽出／签单纸沉」**——只接在审核台 `Review.tsx`。
- **没派独立评审**。按流程，方向探索后的对比页不派评审；本轮是落地实现，视觉已自己截图验证过三屏。
- `src/ws/index.css` 是死副本（只被不进构建的 `ws/main.tsx` 引用），仍有蓝残留，不影响发货。
