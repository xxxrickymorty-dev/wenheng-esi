# 文衡 5180 前端重新设计 · 轮次 01 设计说明

**目标**：给 5180 实验站（`wenheng/frontend/`）做一轮视觉重设计。硬约束一条——主色为绿色；重点在用户交互体验与视觉动效。
**范围决定**：令牌层优先（改 `ws.css` 令牌与共享组件，18 个视图一起变）；动效强度＝克制但有来路（三处基本动效，150–300ms，悬停位移 ≤2px）。
**本轮交付**：三个方向的首屏小样 + 风格对比页。**尚未落 React**，等选定后再动代码。

## 用户任务与主动作

使用者是云南大学图书馆馆员：非技术、每两月用一次、要求数字精确。来首屏是为了**看本期读数 → 走完三步 → 签单下载**。首屏属于「来看内容、处理对象」一类，不放口号，也不放解释这个页面是干什么的段落。

关键状态：未取数 / 取数中 / 已出稿待签单 / 已签发。本轮三个小样画的是**已出稿待签单**——信息量最大，也是落印那一刻所在。

设备约束：桌面 1440×900 为主，馆员在台式机上用。

## 共用地基

**品类**：机构内部数据工作台。地板是「侧栏 + 顶栏 + 卡片网格」，本轮三个方向里两个打破了它。

**标杆**：Linear 首页（真实截图 `tmp/bench-linear/page.png`），对着图拆出 6 条。
- 沿用：产品实样进首屏、两级按钮（实底主操作／文字级次操作）、1px 极低对比描边。
- 换掉：深色底（在否决清单，且档案室是白天看纸）、700 粗体（馆员读惯宋体）、几何无衬线（已有 Noto Serif SC 且中文长文更易读）。

**调性五刻度**：安静偏活一档 · 精致（4px 网格、字号至多 6 档、色相至多 3 个）· 中低密度 · 中偏重 · 庄重。

**共用样例**：三份小样用同一份真实数据，全部来自 `wenheng/out/202609/overview_facts.json` 与 202601–202609 五期台账，无一个编造数字。

## 三张方向卡

| | A 排字房 | B 标本册 | C 游标 |
|---|---|---|---|
| 生成引擎 | 材质×环境：青瓷釉的铅字盘 | 其他领域整套形式：腊叶标本册 | 设计运动：瑞士国际主义 + 精密量具 |
| 首屏骨架 | 56px 书脊 + 整页报告纸 | 3×2 标本网格 | 无侧栏，三段横带 |
| 主色 | 青瓷绿 `#1F5B4A` / 纸 `#F4F1E7` | 苔绿 `#4A7C59` / 羊皮 `#EFE9DB` | 松绿 `#1F5F4B` / 冷白 `#F7F8F6` |
| 字体 | 宋体 27/15，等宽数字 31 | 宋体，等宽期号 19，衬线旧体数字 | 无衬线，等宽数字 33–40 为最重元素 |
| 控件语法 | 零圆角，2px 实边 | 4px 圆角（唯一破零圆角的一档） | 6px 圆角，1px 描边 |
| 动效手感 | 铅字落进字盘，咔嗒 380/14 | 叶子舒展，流淌 180/34 | 游标推过刻度，420/18 |
| 记忆点 | 签单时朱砂印砸落纸面，纸沉 2px 回弹 | 新一期入册，湿润感由淡转实 | 出稿时数字上滚、刻度条同向生长，差 60ms |
| 结构性突破 | 侧栏压成 56px 书脊，纸占满余下全部 | 首屏是六枚标本，不是工作台控件 | 砍掉侧栏，导航收进顶部一行 |

**差异检验**：骨架、字体、色相、主视觉四项两两至多一项重合。B 走到最极端，A 和 C 都打破侧栏套路。 B 的 4px 圆角是刻意破规矩，理由写在下面「待决」里。

## 本轮做了什么

- 三个方向各一份 1440×900 单文件 HTML 首屏，零外部依赖，双击即开。
- 每个方向自己看、自己截图自查过，改掉重叠、裁切和留白断裂后重截。
- 风格对比页 `style-explorer.html`（含方向卡字段，可并排/单张/实际尺寸看，点「选择」复制选择句）。

## 本轮没做什么

- **没落 React**。选定方向后才改 `ws.css` 与组件。
- **没做交互和动效**。方向探索阶段的三个首屏按规矩只做静态主状态。
- **没做响应式**。只做 1440×900 桌面。
- **没派独立评审**。方向探索阶段的对比页先交给人挑，不派评审者。

## 待决 / 遗留

1. **A 的印章对比度 1.61:1 不达标**——这是有意的：尚未签发，所以印是淡的；签单后才落成一枚实印。选定 A 时它会在签单态变实，同时改用 3px 粗描边保证实态达标。
2. **B 要破「零圆角」规矩**。4px 圆角的理由是纸卡材质；选 B 就要改 `frontend/README.md` 规矩 2。
3. **三份小样都不含取数台的轮询态、失败态、空态**。选定后再补状态图。
4. 陈列馆（`view=shelf`）是脱离壳独占整幅的特例，本轮没进候选。
