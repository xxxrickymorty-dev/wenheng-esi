# 文衡 · 新前端（暂名 `frontend/`）

> **栈未定，先出静态件。** 这个目录不是工程——没有 `package.json`、不装依赖、不构建。
> 它是新前端的**底座**：一套定好类名的静态 HTML ＋ 共享 CSS。将来换什么栈，
> 每块都能机械搬成组件。

## 这是什么

rick 2026-10-17 定：**在 wenheng 内开新目录、接同一套后端、先不定栈先出静态件。**

设计基准是 `web/mockups/出报告-重设计/汇-绿蓝.html`（合成稿「汇」）——
rick 定它最好看，于是扩成整套。视觉分工写死在 `css/tokens.css`：

- **蓝 ＝ 场**（数据 / 时序 / 读数）
- **绿 ＝ 器**（工序 / 戳印 / 签发）
- 红色只作警戒（阈值虚线、复核 PENDING），全站两处以内

## 目录

```
frontend/
  README.md          ← 本文件
  css/
    tokens.css       ← 设计令牌（换主题只改这一份）
    base.css         ← 壳、表格、数据面板、按钮、页脚、布局工具
    devices.css      ← 四件签名器件
  kit.html           ← 零件目录（每块活摆出来 + 类名 + 组件映射）★ 先看这个
  index.html         ← 入口：零件 ＋ 各屏
  screens/
    00-出报告.html … 07-问文衡.html
```

双击 `kit.html` 或 `index.html` 就能开，不需要起服务。

## 用词（全站一份，见《全站-冗余收敛对照稿》定词表）

- **取数**（机器）／**取数核验**（人的步骤）
- **一键生成**（机器）／**生成初稿**（人的步骤）
- **5 站 5 屏**：取数核验 · 选章节 · 预测选模 · 生成初稿 · 核验定稿
- **屏题 ＝ 站名**，不另起名
- 状态词只两套：**任务**（进行中／已完成／未开始）＋ **签发**（未签发／已签发／签发已失效）
- 动作叫 **签单**，状态叫 **签发**；「签名」只指数字签名

## 规矩

1. **不引 CDN**。字体、图形全在本目录或用系统字体，离线双击能开。
2. **零渐变、零投影、零玻璃、零圆角面板**。层次靠字号与色阶。
3. **细线只用在该物本身的结构上**（翻牌的牌缝、水位的刻度、戳框、印框、表格线）。
4. **静态样式落类，只有动态值才内联**（高度、百分比这类来自数据的值）。
5. 面向馆员的文案讲人话，不出技术术语。

## 边界（要 rick 知道）

- 根目录 `AGENTS.md` 的「前后端分工」写的是**前端只碰 `web/**`**。本目录在 `web/` 之外，
  所以那份契约文档需要补一句，或者明确本目录是并行实验、不动契约。
- `tests/test_stack_contract.py` 盯的是 `web/dist`，不覆盖本目录——因为还没定栈、不构建。
- 后端接口仍走 `server/app.py` 的 `/api/*`，本目录只是另一个客户端，不改接口。
