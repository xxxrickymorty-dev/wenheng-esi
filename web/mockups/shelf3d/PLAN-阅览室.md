## 0. 一句话定位

**阅览室是环境，不是主角。** 主角永远是书架上的书。
阅览室只回答一件事——「这是什么地方」：一间大学图书馆的阅览室，安静、有年代感、暖光。
任何会把视线从书上抢走的细节，一律砍掉或压暗。

## 1. Blender / MCP / 脚本 · 各管哪一段（先分清，避免误用）

| | **blender-mcp（交互）** | **headless 脚本（生产）** |
|---|---|---|
| 干什么 | 边看边调：曲面弧度、布线、比例 | 批量导出顶点数据 |
| 怎么起 | Blender **GUI** + 插件面板点「Start MCP Server」 | `F:\blender\blender.exe --background --python exp.py` |
| 产物 | 无（只是建模过程本身） | `window.WH_MESHES[...]`（base64 顶点） |
| 用在哪 | ④ 台灯罩的弧、⑤ 扶手椅的软包曲线 | ① ② ③ ⑥ 全部导出与复核 |
| 已装 | ✅ `mcp-for-blender` 2.0.3（MIT）+ 插件 `blender_mcp.py` | Blender 5.2.2 LTS @ `F:\blender\blender.exe` |

**安全面（已配置）**：`BLENDER_MCP_SAFE_MODE=1`（脚本里的读写文件/起进程/联网会被拦）、
`DISABLE_TELEMETRY=true`（连匿名用量统计也关）。插件 socket 只听 `localhost:9876`，无鉴权——**别映射到公网**。

⚠️ 插件**在 headless 下自动不起**（`bpy.app.background` 直接 return）。
所以 MCP 只用于「人在 Blender 看着调」的场合；自动化一律走脚本。这正好与生产分工一致。

⚠️ **安全模式下连 `import sys` 都会被拦**，外部 `.py` 更读不了（`import wh_models` 直接拒绝）——
只放行 `bpy` / `bmesh` / `mathutils` 与极少数纯标准库。所以 **MCP 里跑的建模代码要内联**，
不能 `import` 仓库里的模块；几何的**唯一事实源**仍是 `wh_models.py`（无头脚本用它），
MCP 内联那份是「让你在 Blender 里看得见」的副本，改了几何要两边同步（或只改 `wh_models.py` 再内联过来）。
已实测（2026-09-22）：`import sys` → `Rejected by safe mode`。

## 2. 空间构成（从镜头里看，从近到远）

默认机位：`fov 32`（长焦压缩）、相机 z≈5.05（整柜）/ 2.55（单层焦点）。

| 层 | 内容 | 谁来做 | 面数 |
|---|---|---|---|
| **前景** | 三层书架 + 书（已有） | Three.js | 已有 11366 |
| **中景** | 阅览桌 + 绿罩台灯 + 扶手椅 | **Blender → 顶点数据** | 见 §3 |
| **背景** | 高窗（套线脚+窗台）、踢脚线、地毯、后墙 | **窗套/踢脚/地毯走 Blender；墙/地面仍是 Three.js 平面** | 见 §3 |
| **远景** | 两侧书架剪影 | **贴片**（方案 C，不进 Blender） | 0 |

**取景纪律**（决定「高级感」）：

1. **桌面只露一角**（右下前景，被画幅裁切）——空间延伸感；整张桌摆进来 = 玩具箱。
2. **椅背侧对或背对镜头**——正对镜头的椅子会变成「主角」，跟书抢戏。
3. **窗在左、桌灯在右**——光的方向有叙事（下午的天光 + 人刚走开的台灯），不是对称布光。
4. **背景亮度比前景低 1–2 档**；画面第二亮点是台灯光池，第一亮点永远是焦点层的书。

## 5. 材质（归代码，沿用现有配方；Blender 只出几何）

| 材质槽 | 用在 | 参数（已有配方） |
|---|---|---|
| `wood` | 桌面、地板、窗套、踢脚 | `roughness .62`，暗胡桃 |
| `metal` | 灯座、灯杆、椅腿 | `metalness .90 + roughness .19 + clearcoat` |
| `fabric` | 椅面软包 | `sheen .30`（这层让它像布） |
| `glass` | 窗格 | 透明 + 微反射 |
| `carpet` | 地毯 | 高粗糙度、低对比图案 |

颜色贴图**必须声明 `SRGBColorSpace`**（坑 1）；法线/粗糙度图**不能声明**（保持线性）。

## 7. 验收判据（不许用「我觉得好看」结案）

1. **几何一致性**：Blender 里量的尺寸 = 屏幕上量的尺寸，**±1mm**。
2. **零外部请求**：`file://` 双击即开，控制台无网络请求。
3. **面数不超预算**：单件与总量都对上 §3。
4. **光池可测**：台灯点亮前后桌面区域像素差达阈值（不是「感觉亮了」）。
5. **背景不抢戏**：背景区域平均亮度比书架区低 1–2 档（可量）。
6. **零 `pageerror` / `console.error`**；`renderer.info.render.triangles > 0`。
7. **诚实标注**：真机 GPU 的实时阴影、动效手感——静态稿证明不了，单独标「未验证」。
