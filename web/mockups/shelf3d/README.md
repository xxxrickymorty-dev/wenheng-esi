## 这一版改了什么（对照实测配方）

| 配方项 | 昨天那版 | 这一版 |
|---|---|---|
| **色彩空间** | 没声明 → 贴图按线性解读，整体发灰发粉 | 颜色贴图全部 `SRGBColorSpace`（法线/粗糙度保持线性） |
| 环境光照 | 有 IBL，但强度默认 1.0 | `environmentIntensity .55`（让擦光说话） |
| 主光 | 无方向光、无投影 | 方向光从左上前方，**唯一投影的那盏** |
| 五盏擦光 | 3 盏泛泛的面光 | 5 盏**各自对准一个部件**：布面柔光箱 / 扫烫金 / 扫书脊 / 扫书口 / 封底柔光箱 |
| 材质 | 全 `MeshStandardMaterial` | `MeshPhysicalMaterial` 分层：布 `sheen .30`（这层让它像布）/ 烫金 `metalness .90 + clearcoat` / 纸 `roughness .95` |
| 法线与粗糙度 | 只有颜色图 | **同源**：一个高度场导出颜色 + 法线 + 粗糙度（凹处更涩） |
| 陈列方式 | **书脊朝外**（满屏一模一样的书脊） | **封面朝外**（与参考站一致）：四期封面各不相同，一眼认出是哪一期 |
| 架子 | 整面柜子（顶檐/侧板/踢脚全上） | **极简**：背板 + 层板 + 踢脚（架子抢戏就没有"陈列"了） |
| 背景 | 花木纹 | **暗色纯面 + 极缓渐变**（花木纹是廉价感最大的来源） |
| 封面 | 纯色 + 波纹 | 加**书名（竖排）+ 期次 + 钤印**，画布比例 = 书封比例（否则字被拉长） |
| 接触影 | 1 片贴片（22%） | 接触影 + 落地投影两片（85%），朝向与主光一致 |

## 已知差距（诚实清单）

1. **书在画面里偏小** —— 参考站 7 本铺满画幅（左右裁切），我们 4 本居中留边。
2. **封面图形更简单** —— 参考站是分层几何构成；我们是同心波纹 + 书名（**这是设计任务，不是渲染任务**）。
3. **影子偏弱** —— 见下。
4. **实时阴影在软件渲染下不生效** —— 无头截图环境（SwiftShader）里 `shadowMap` 配好了也不出影子，
   所以接触影/落地投影是**贴片烘的**（参考站自己也用贴片做接触影）。
   真机 GPU 上实时阴影会生效，但**这一条必须在有显卡的机器上复验，静态稿证明不了**。

## v3（2026-09-22 下午）：三层 + 焦点切换

| 项 | 做法 |
|---|---|
| 三层 | 顶＝年报 / 中＝学科发展态势 / 底＝ESI 双月报告（rick 定的信息架构） |
| 切换 | **相机推近 / 拉远**（620ms，easeInOutCubic，**可打断**）——不是换页面、不是淡出淡入 |
| 焦点表达 | 焦点层受光最亮；非焦点层的书**压暗到 55%**——用光说"你在哪层"，不用标签 |
| 空位 | 每层末尾留**虚线方框**（该期还没出刊）。⚠️ 虚线要画粗（14px/256）：细线在远处被 mipmap 平均掉，等于没画（实测差异从 10/255 掉到 104/255 才叫看得见） |
| 未出刊系列 | 放**示意书**（封面盖「示意」水印 + 灰印）——不假装真出过 |
| 操作 | 点某层 / ↑↓ 换层 / Esc 或点空白退回整柜；右侧按钮同步高亮 |
| 层标 | 层板前沿左侧一枚**小铜牌**（第一版做成 2 米宽，像大字报，已改） |
| 实测 | 3 层 6 本 · 11366 三角面 · 零报错 · 相机 z 5.05 ↔ 2.55 |
