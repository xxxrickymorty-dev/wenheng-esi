## 3. 作用范围

```
设置面板（ModelPanel）
  ├─ 系统轨：localStorage → <html data-skin-sys data-font>
  │            → tokens.css（--sys-*）→ 工具条 / 左壳 / 主壳 / 全站界面
  └─ 报告轨：生成请求带 template / skin-rpt / font
               → 后端把 --rpt-* token 注入内联 CSS → 独立单文件 HTML
               → 图表发丝线颜色同步取 --rpt-*  → 深色反白
               → Word 出口：本次不跟（保持原样）
```

🔴 **报告是后端生成的独立 HTML，读不到浏览器 localStorage** —— 偏好必须随生成请求传后端。
🔴 **图表色硬编码**在 `src/flexible/mdview.py:506-510` `_INIT_JS` 的 `INK/MUT/GRID/FONT`、`web/src/charts/options.ts:13`；matplotlib 侧 `src/charts.py:1038`、`src/native_report_charts.py:333`。不参数化就「纸换了、图没换」。本轮静态稿已证明图表能随皮肤变量换色，落地时照此做。
