# 阅览室集成稿来源说明

> 状态：T09 静态审核稿；用途是核对动线、信息归属和访客可见范围。稿件没有接入登录、后端或真实馆藏，不代表正式页面已上线。Rick 审核本稿后，后续任务仍须另行确认。

## 本稿呈现了什么

- **馆员首屏**：当前期次与上期签发状态由系统提供；先读本期任务状态，再按“数据准备 → 生成报告 → 核对补录 → 签单”进入下一步。读取中、暂无任务、读取失败和状态已载入可切换查看；已载入示意明确进入“报告与校验”。按钮只演示页面内动线，不发请求。
- **访客首屏**：有馆藏、空馆藏和安全预览读取失败均可切换查看；馆藏区明确按每个安全预览期次呈现一张卡片。馆藏卡片和封面只示意样式，不指向真实期次。
- **访客阅读**：封面、目录、名词解释三项可切换；支持键盘方向键切换、Home/End 定位、Esc 归架和可见的返回按钮。稿中没有报告全文、数值页、图表、下载或运行状态。
- **馆员入口**：报告、学科表、趋势、预测、数据来源与口径、运行档案只显示入口说明，不重画数值页面。两类信息的职责在下文分别列出。
- **窄屏与动效**：布局在窄屏转为单列；保留键盘焦点样式；系统开启“减少动态效果”时关闭平滑滚动和过渡效果。

## 三个来源的借用与去重

| 来源 | 已有内容与本稿借用 | 本稿不带入 |
|---|---|---|
| `wenheng/web/` 正式馆员工作区 | 复用馆员从本期任务进入工作、再按需到报告和分析页面的层级。正式代码已有生成台、报告、审核、分析、预测、数据来源和运行档案等职责；本稿用入口说明把它们串起来。 | 不复制 React 组件、不复制真实运行状态或业务值、不改现有角色判断。报告趋势归报告页，学科表归分析台，预测归预测台/生成台。 |
| `wenheng/数字图书馆阅览室/` 独立原型 | 借用“馆藏卡 → 取阅 → 封面 / 目录 / 名词解释 → 归架”的阅读顺序与纸本质感。阅览可直接从目录和标签进入，不需穿过场景。 | 不引用 `app/report-data.json`、原型 `data.js`、3D 场景、音效、原型建筑图或第三方资源；不另建站点。建筑模型和此前被撤销的游客视觉不恢复。 |
| `设计文档/前端设计预览/云南大学图书馆学科分析平台/` | 只借鉴学科信息的检索层级、表格信息分组和清楚的学科入口；本稿将这些入口送回正式馆员页面。 | 不复制 `data.js`、指标、趋势序列、预测结果、学科列表或图表；不建立第二套数据源、访客数据页或预测解读。 |

## 权限展示矩阵

| 身份 | 可见内容 | 明确不提供 |
|---|---|---|
| 馆员 admin | 本期状态和下一步；报告、校验补录、签单；馆员专用的学科表、趋势、预测、来源说明和运行档案入口 | 未确认的状态或编造的业务值 |
| 访客 guest | 每个可阅期次的封面、目录、名词解释；空馆藏或读取失败的说明 | 全文、DOCX、数值页、图表、附件、下载、趋势、预测、运行状态；签发状态不改变此范围 |

权限须由登录态、后端按角色投影和资源路由共同执行。不能把完整内容放进页面再用 CSS 隐藏。T09 的身份切换仅供检查两种布局，不模拟或替代权限。

## 文案、释义和素材来源

- 页面品牌只用项目文字标识，没有嵌入或仿制正式校徽；没有使用真实建筑照片。
- 书封由本文件内的 CSS 图形绘制；小图标用内联 SVG；字体使用设备已有字体。没有远程图片、字体、脚本、样式、音频或其他外部请求。
- 目录标题来自现有服务端安全预览的固定标题白名单，没有目录页码。
- 名词条目名称来自安全预览白名单。卡片里的短释义只是为了审阅版式的概括文案，不是已核对的报告原文；后续必须直接读取安全预览返回的原释义，不可把这些占位文字当成正式业务口径。
- 馆藏卡和阅读器重复显示同一标签“示例期次 · 实际期次由安全预览提供”，它不包含期次值。正式页面须逐期读取安全预览返回的真实期次；空馆藏和读取失败时继续显示各自的状态说明。
- “馆藏卡”“本期状态”示例均不含真实期次、指标、预测、人员姓名或报告正文。

## 与现有旧陈列馆的关系

旧入口 `/app/shelf/` 和服务端按角色返回的安全预览需保持可用。当前旧页面的书页组成方式与本卡访客白名单边界不一致，因此它只作为兼容入口和过渡对象，不作为新游客权限的视觉依据。T09 不改旧页面、静态资源或服务端；在新版直达、刷新、安全预览、窄屏和回滚路径验收前不得退役旧实现。新版出问题时仍可按旧入口回退。

当前正式工作区仍有报告与台账等 guest 导航项；本稿只表达应收敛到安全馆藏的目标动线，不表示导航或权限缺口已修复。T10 先复核已有安全投影和直接资源访问；随后再修订正式入口。
