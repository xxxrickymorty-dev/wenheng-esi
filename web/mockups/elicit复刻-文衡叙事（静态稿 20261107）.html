做学科分析的 AI 工具不少。文衡的底气是四句话。

22

规模

一次出齐 22 学科口径：90+ 张图、20 张表，同源直出。

0

准确

运行期经过 LLM 的数字是 0——正文全部由 sentences.py 骨架拼装。

1

透明

每个数字都能指回台账的某一格：逐格可回核，逐期可回测。

3

不止对话

产出的是可签单的文件——报告、对照、红件清单，不是聊天记录。

FAQ

常被问到的四件事

数据从哪里来？

Clarivate ESI 原始包 45 期与 InCites 快照，落入动态监测表；所有产出只认台账，不认模型记忆。

给谁用？

学科建设办公室、研究生院、院系与图书馆——要台账级证据做决策的人。

怎么保证准确？

运行期 LLM 不进数据路径；正文由句骨架拼装；验收判据是「报告数字对」——与人工原件逐格对照，不符为 0 才许签单。

部署在哪？

本机确定性流水线＋演示站单进程（8080）；产物三件套：报告初稿 / 对照差异报告 / 红色件清单。

省下的是时间，换来的是判断。
