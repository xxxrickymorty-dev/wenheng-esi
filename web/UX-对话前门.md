## 0. 四问（UX.md §三，缺一不许动工）

| 问 | 答 |
|---|---|
| **谁、什么场景** | **馆员（admin）**，办公室 **Windows** 桌面；演示现场也会走一遍（评委在旁边看） |
| **现在怎么做、哪一步最烦** | **完全手工**——Excel 里算、Word 里画图写报告。**最烦**：整条链全靠人记——数据齐没齐要自己记、缺哪件要自己找、期次（"9 月的报告"到底哪期）也要自己记；**猜错就是整期返工** |
| **用完之后什么变了** | 说一句话就走到位——**盘点不用记、缺件不用找、期次不用猜**（系统先说出来让你确认）。从"翻文档＋记流程"变成"说一句＋跟一条轨迹" |
| **怎么知道做对了** | 他能验证的一句话：**"我说'做 9 月的报告'，它说出来的期次和数据状态跟我心里的一致；不一致它先停下问我。"** 出稿后还有一条他会用的：**每个数字点开都能指回台账那一格** |

> 注：第 2 条与 `UX.md` §一「现在怎么做」栏（写的是双击 `一键出报告.bat`）不同——
> 那一栏描述的是**流水线建成之后**的走法；rick 在此处答的是**前门要替代的那条路**（纯手工）。

│            │                                                         │
│ 工作台▾     ├─────────────────────────────────────────────────────────┤
│ （在顶栏）   │  ┌───────────────────────────┐  [↑/■]                  │

- **左＝对话历史**（纯标题，无副标题）；**中＝对话流**（列宽 1060px）；**底＝输入框**
- **顶栏**：`工作台 ▾`（五个页面按需打开，深链保留）｜配色｜**期次槽**｜**意图槽**（槽位可看、可清）
- 输入框**流式进行中原地变停止键**（↑ → ■），点它就停

## 2. 四个视图

| 视图 | 看什么 | 要点 |
|---|---|---|
| **⓪ 新对话（空态）** | 「本期任务 · 202607」三步条：①取数 ✓ → **②核对并并入 ← 卡在这** → ③一键生成 | **第一屏回答「我现在该做什么」**（UX.md §七）；空态＝一句话＋一个动作 |
| **① 9 月的** | 盘点 4 件（2 缺）→ 金底引导两条路 → [改做 202607 的] | **数据未发布就停下反问**，不静默猜 |
| **② 流式中** | 轨迹 ①-③ 逐段出（③ 带光标）＋「正在出稿…」 | **真流式**（复用 `generate_stream` 的 NDJSON）；输入框是 ■ |
| **③ 出好了** | 校验一次通过 → 三件套 → **覆盖确认**（行内二次确认）＋ 回滚 | 唯一会问一次的地方；**不带着问题出稿** |

## 3. 状态清单

| 状态 | 界面 | 用户能做 |
|---|---|---|
| 新对话 | 本期任务三步条 + [去核对] | 说一句 / 点主按钮 |
| 期次已识别 | 顶栏槽位亮起 + 「我按…理解」 | 改期次 / 继续 |
| 盘点缺件 | 逐件 ✓✗ + 金底两条路 | 等发布 / 改做最新一期 |
| 盘点齐 | 三步条 + [去核对 ▸]（跳表格页） | 去核对 |
| 出稿中 | 轨迹逐段 + 正在出稿… | **点输入框那个键停** |
| 校验没过 | 哪条没过 + 「自动修复」/「需人工接手」 | 看明细 / 接手 |
| 出好了 | 三件套 + 覆盖确认 + 回滚 | 下载 / 覆盖重出 / 回滚 |
| 产物已存在 | 覆盖确认（行内二次确认） | 覆盖 / 保留 / 回滚 |

## 4. 体验判据自检（UX.md §四 逐条）

- 第一屏回答「我现在该做什么」？—— ✅ 空态即本期任务视图
- 出错时是「哪里错了＋下一步」？—— ✅ 盘点逐件＋两条路；校验不过写明细
- 明确的「完成」信号？—— ✅ 「出好了」＋三件套＋校验数字
- 关掉页面/换设备状态还在？—— ⚠️ **待定**：槽位与对话是否进 URL／服务端（P1）
- 键盘可达、窄屏可用、断网有交代？—— ✅ 键盘（跳转链接/焦点环/点击区 ≥44px）；⚠️ 窄屏未做（桌面单用户，P1）
- 文案不出现技术术语？—— ✅ 已把文件路径改成「已有 / 缺」；术语走 `GLOSSARY.md`
