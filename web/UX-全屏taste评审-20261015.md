## 横切问题（按修复顺序——后项救不了前项）

1. **焦点尺度**：除 07/15/12 外，各屏最大字号 21–22px，「一切都中等」。修法：每屏立一个主角——报告台已示范（44px 期题）；工作台把「本期报告已就绪」这类结论句升到 28–32px；页题可微升。牵动 index.css 的 h 尺度（一次性）。
2. **界面语言里的内部键**：`_overview` / `AgriculturalSciences` / `bigtable` / `dcharts` / `cover` / `threshold_1pct` 等直接上屏。修法：分组/字段名加一层中文映射（图册、对勘本、红色件 chips 优先）。这是「文衡味」问题，不是美观问题。
3. **装饰性编号与占位**：预测选模 01/02、运行档案 01 → 去编号（位置即顺序）；「正在跑…」虚线框 → 色阶块或真进度；**灵活报告空态**（首屏空白）→ 补空态卡（改版提案里已含）。
4. **动效层全站缺席**：目前近乎零动效。修法：把「灵活报告静态稿」里那套（头卡/分栏入场错峰＋栏内逐段＋按下回弹、reduced-motion 降级、脚本失败不藏内容）抽成统一动效层，落 index.css。
5. **tells 清单（小项）**：登录页玻璃卡→实色；eyebrow（登录/报告台/问文衡/陈列馆）→ 折进标题或首句；✧ 装饰点删除；「去④核验与定稿」④ 圈号改文字指路。

## 保留判断（可辩护项，不动）

- 细线/描边＝工作台结构语言（表、卡边界）；等宽＝数字对齐与真实文件名/键（溯源、图册、取数清单）；纸面暖色＝品牌基调；卡片阴影＝浮层与印记（07 印记链）；步进条①-④＝真顺序（<ol> 语义），非装饰。
- 逐格溯源/红色件/图册的信息密度是**产品主张**（可核验），不为「极简」削内容。
