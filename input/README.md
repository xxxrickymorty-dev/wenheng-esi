# input/ — 输入契约

本目录**不入库**（见 `.gitignore`）。台账属馆员维护的业务数据，体积大且随时更新。

## 放什么

```
input/
  <期次>/               # 六位年月，如 202607、202609
    监测表.xlsx          # 《云大全学科排名、阈值动态检测表.xlsx》
```

## 期次规则

**第 N 期 = 2N−1 月**。例：

| 报告期次 | 台账年月 |
|---|---|
| 2026 年第 1 期 | `202601` |
| 2026 年第 2 期 | `202603` |
| 2026 年第 3 期 | `202605` |
| 2026 年第 4 期 | `202607` |
| 2026 年第 5 期 | `202609` |

流水线**自动检测**当期与上期（以「总被引」sheet 最后一个有数据的期次为准），
所以新增一期只需把台账放进新的期次目录，无需改代码。

## 台账是唯一事实源

- 所有数字**只来自台账**，运行期 LLM 不进数据路径。
- **禁止用 openpyxl 存盘改写台账**——会丢掉 6 张图表、条件格式与打印设置。
  若必须写回，只能用 zip 级 XML 替换（见 `src/extract_1permille.py`），
  且改前先备份到 `../归档/台账备份_<日期>/`。
- 新期次列一律**贴在已有列后面**，按列追加，绝不覆盖历史列。

## 缺台账时会怎样

`run_pipeline.py` 在 parse 步会抛 `FileNotFoundError` 并打印期望路径，
不会静默产出空报告。

数据下载与贴表由有权限馆员完成，agent 不碰——详细步骤见 `../docs/操作手册（馆员版）.md`。
