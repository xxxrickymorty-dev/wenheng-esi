# input/ — 输入契约（2026-10-13 起）

本目录**不入库**（见 `.gitignore`）。动态监测表属馆员维护的业务数据，体积大且随时更新。

## 放什么

```
input/
  云大全学科排名、阈值动态检测表.xlsx   # 动态监测表（母本）——只此一份，含全部期次
```

- **一份母本、全部期次**：馆员每期动态更新同一张表（按列追加，绝不覆盖历史列）；
  本目录是它的**运行时输入副本**——开发机与部署机同路径，流水线/开跑口/问答回落/
  盘点/e2e/部署包都只读这一份。
- **每期不再另存表**：当期取数核对副本落 `out/_acquisition/<期次>/监测表.xlsx`
  （ADR-0004 的「审的＝写的」载体），不叫「监测表」，也不进本目录。
- 馆员原件在 `../数据与复现/云大全学科排名、阈值动态检测表.xlsx`（「并入台账」的
  写入面）。并入成功后 `tools/acquire.py merge` 会自动把原件同步到本目录；
  手工改过原件后跑 `uv run python tools\sync_input_ledger.py`。
  部署包预检会核对本目录与原件 sha256，不一致直接拒绝打包。

## 期次规则

**第 N 期 = 2N−1 月**。例：

| 报告期次 | 数据截止月 |
|---|---|
| 2026 年第 1 期 | `202601` |
| 2026 年第 2 期 | `202603` |
| 2026 年第 3 期 | `202605` |
| 2026 年第 4 期 | `202607` |
| 2026 年第 5 期 | `202609` |

流水线**自动检测**当期与上期（以「总被引」sheet 最后一个有数据的期次为准，口径在
`src/period.py`），所以新一期数据并入后直接开跑，无需改代码。历史期补跑用
`run_pipeline.py --period <期次>`（母本 + 目标期切窗——"07 的报告不读 09 的数据"
在消费层强制）。

## 动态监测表是唯一事实源

- 所有数字**只来自动态监测表**，运行期 LLM 不进数据路径。
- **禁止用 openpyxl 存盘改写**——会丢掉 6 张图表、条件格式与打印设置。
  若必须写回，只能用 zip 级 XML 替换（见 `src/extract_1permille.py`），
  且改前先备份到 `../归档/台账备份_<日期>/`。
- 新期次列一律**贴在已有列后面**，按列追加，绝不覆盖历史列。

## 缺母本时会怎样

`run_pipeline.py` 在 parse 步会抛 `FileNotFoundError` 并打印期望路径，
不会静默产出空报告。

数据下载与并入由有权限馆员完成，agent 不碰——详细步骤见 `../docs/操作手册（馆员版）.md`。
