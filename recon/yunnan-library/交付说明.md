## 成品在哪

| 文件 | 说明 |
|---|---|
| `src/createYNULibraryModel.ts` | 主工厂（流水线最终期优化版产物，含 apply_refine 注入调用）。导出 `createYNULibraryModel(options)`、`createYNULibraryLookDevLights(mode)`、`createYNULibraryEnvironment(renderer)`、`frameYNULibraryCamera`、`createYNULibraryPresentationComposer`、`createYNULibraryInspectControls`、`configureYNULibraryRenderer` |
| `src/refineYNULibrary.ts` | 手工精修层：线性阵列（窗格/柱廊/台阶/屋脊/栏杆/树列/绿篱）、坡屋顶几何、拱窗、半管玻璃拱、水盘边缘、设备排。**经 `tools/apply_refine.py` 在每次流水线生成后幂等注入**，不要手改主工厂里被注入的两行 |
| `preview/` | 自检预览（vite + web 的 three；`?view=` 六机位、`?az=` 转台、`?stripped=1` 去贴图模式、`/material-evidence` 参考贴图路由） |
| `render/final/` | 十张成品渲染（六机位 + 四方位转台）+ 对比表 + 评分 |
| `object-sculpt-spec.json` | 规格（交通全景：94 组件 28/32/34、22 材质、7 重复系统、7 条审查记录、strict-quality PASS） |
| `material-evidence/` | 材质证据：每材质裁图 + PBR 提取报告（大贴图不入库，`tools/run_pbr_extraction.py` 可复现） |
| `.img2threejs/state.json` | 流程状态：**complete**（全部门禁通过） |

## 接进演示站（下一步）

`web/src/library/scene/architecture.ts` 的 `buildLibraryArchitecture` 是现役外观模型。
接法（建议由 web 会话在空窗期做）：
1. 把 `src/createYNULibraryModel.ts` + `src/refineYNULibrary.ts` 拷进 `web/src/library/scene/`（改 import 路径，refine 是相对导入可直接跟随）；
2. `LibraryScene` `exterior` 分支改调新工厂；`lights` 用 `createYNULibraryLookDevLights('reference')`（或自配光）；
3. 参考贴图路由 `/material-evidence/*` 只在 recon 预览有效 —— 进站时把相关材质的 `referencePbr.maps.*.url` 清空或复制贴图到 `web/public`，否则退回程序化 canvas（工厂已内置 fallback）。
4. 性能：场景约 27.5 万三角形 / 每相机 ~194 draw calls（阴影通道使统计到 388）；建议 `castShadow` 只开大件或移动端关阴影。

## 已知限制（如实）

- 墙面砖色为**运行时压平的纯色**（参考照片贴图带常春藤绿斑，独立验收标为噪声；证据仍在 spec/材质证据里）；穹顶保持参考贴图网格。
- 门廊内退玻璃与全部窗玻璃同样压平为深青灰，柱廓可读性优先。
- 后立面（北侧）为航拍推断；庭院玻璃拱/天窗为简化读法。
- 水池边缘波瓣、喷泉环为近似（lathe + 圆柱波瓣）；树冠为双球簇。
- 三角/描画预算略超 spec 目标（250k/150），已记录；进一步减面留待集成期。

## 复现全流程

```powershell
python tools/build_spec.py          # 规格（确定性，东西镜像由循环保证）
python tools/apply_pbr.py           # 材质证据回填（幂等）
python tools/run_pbr_extraction.py  # 21 材质 PBR 重提取（换裁图后）
python "…/img2threejs/forge/stage2_spec/validate_sculpt_spec.py" object-sculpt-spec.json --strict-quality
python "…/img2threejs/forge/stage3_build/generate_threejs_factory.py" object-sculpt-spec.json --out src/createYNULibraryModel.ts --pass-id optimization-pass --force
python tools/apply_refine.py        # 注入精修层
```
