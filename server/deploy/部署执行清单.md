## 2. 处理 nginx 占用 8080（二选一）

### 方案 A（推荐）：uvicorn 退到 8081，nginx 反代 —— 对外仍是 8080

```bash
cat > /etc/nginx/sites-available/wenheng <<'EOF'
server {
    listen 8080;
    server_name _;
    client_max_body_size 100m;          # 上传台账用
    location / {
        proxy_pass         http://127.0.0.1:8081;
        proxy_set_header   Host $host;
        proxy_set_header   X-Real-IP $remote_addr;
        proxy_set_header   X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;
        proxy_http_version 1.1;          # SSE 用长连接
        proxy_buffering    off;          # SSE 实时进度必须关缓冲
        proxy_read_timeout 600s;         # 流水线约 3 分钟，留足余量
    }
}
EOF
ln -sf /etc/nginx/sites-available/wenheng /etc/nginx/sites-enabled/wenheng
rm -f /etc/nginx/sites-enabled/default        # 删掉欢迎页，否则 8080 仍被它吃掉
nginx -t && systemctl reload nginx
```

**反代口径（别改成 nginx 直接 root 到 `web/dist`）**：`/app` 是 SPA 但**不是**纯静态——
它和 `/api/*` 同源、共用会话 cookie；把 `/app` 交给 nginx 直接吐文件会绕过 uvicorn 的
`Cache-Control: no-cache`（改了看不见）与后续路由。**全部 proxy 到 8081 就对了。**

然后**带 PORT 环境变量**跑部署脚本：

```bash
PORT=8081 bash /opt/wenheng/server/deploy/deploy_linux.sh http://116.62.37.161:8080
```

### 方案 B：直接停掉 nginx，uvicorn 独占 8080

```bash
systemctl stop nginx && systemctl disable nginx
bash /opt/wenheng/server/deploy/deploy_linux.sh http://116.62.37.161:8080
```

## 4. 部署后必须手工做的两件事

### 4.1 改登录口令（脚本不会替你改）

脚本只换 `WENHENG_SECRET`；**口令没有默认值**——`.env.example` 里为空（2026-10-02 起），
首次使用先按下面 4.1 设口令；没有口令时登录一律被拒（空口令登不进来）。

```bash
NEWPASS="Wh$(tr -dc 'A-Za-z0-9' </dev/urandom | head -c 10)@26"
sed -i "s|^WENHENG_PASS=.*|WENHENG_PASS=$NEWPASS|" /opt/wenheng/server/.env
chmod 600 /opt/wenheng/server/.env
systemctl restart wenheng-demo
echo "新口令：$NEWPASS"        # 记下来给组委会
```

### 4.2 确认 SECRET 真的换掉了

```bash
grep -c 'change-me\|wenheng-demo-secret' /opt/wenheng/server/.env   # 应为 0
awk -F= '/WENHENG_SECRET/{print length($2)}' /opt/wenheng/server/.env  # 应为 64
```

### 4.3 游客账号（guest，只读）

演示用的**只读账号**：`guest / guest@2026`（`.env` 的 `WENHENG_GUEST_USER/PASS`，默认值）。
2026-09-28 二次裁定：游客入口已**移入工作区导航的「陈列馆」**（管理员从工作区进入陈列馆看同一份游客投影）；
登录页不再放游客按钮（`WENHENG_SHOW_GUEST` 自本日起不再影响界面，已移除）。若要给访客单独入口，
用游客凭据直接 `POST /login`（下方口令照旧生效）。

游客仅可在陈列馆查看每期报告的**封面、目录和名词解释**；不能看全文、下载、指标或数据档案。
其余工作台和旧报告路由均由后端拦截，不能只靠隐藏按钮。**公网部署时与管理员口令一起改**

## 8. 首次实跑踩到的坑（2026-09-17 在这台机器上真踩过）

1. **`fc-list` 根本没装** —— 脚本第 1 步装了 `fonts-noto-cjk`（字体文件确实在
   `/usr/share/fonts/opentype/noto/`），但 fontconfig 工具链不在，`fc-list` 报 0 条，
   看起来像"字体没装上"。补一句 `apt-get install -y fontconfig && fc-cache -f` 即可，
   之后 `fc-list | grep -ci cjk` = 30。
   判断有没有真的缺字，别只看 fc-list，直接让 matplotlib 渲一张中文图看警告：
   `缺字警告: 0` 才是真的没事。
2. **备份别放在 `out/` 下叫 `202607.bak`** —— `jobs.PERIOD_DIR_RE = ^\d{6}` 会把它当成一个
   期次扫进首屏印记链（它里面有 `red_slots.json`）。备份挪到 `/opt/backups/` 之类。
3. **8088 已被 docker-proxy 占**（与文衡无关），别顺手改配置把它搅了。
4. **nginx reload 是优雅重启**：reload 后立刻 curl 可能仍命中旧 worker（本次表现为
   配完反代先返回 404，几秒后才变 502）。看到意外响应先等两秒再判断。
5. **脚本不会替你改口令**，只换 SECRET（见 §4.1）。
